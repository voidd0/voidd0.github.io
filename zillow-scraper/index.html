Zillow Search Scraper: how to get Homes for Sale, Rent and Sold as JSON/CSV (API, Python, no code)

This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/zillow-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "locations": [
    "Austin, TX"
  ],
  "listingType": "for_sale",
  "maxItems": 20

Input fieldTypeWhat it does
locationsarrayCities, ZIP codes or neighborhoods such as Austin, TX or 78701.
listingTypestringWhich Zillow listings to read for the locations above.
searchUrlsarraySearch result pages copied from your browser, for example https://www.zillow.com/austin-tx/ or a filtered search.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/zillow-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'locations': ['Austin, TX'], 'listingType': 'for_sale', 'maxItems': 20}

run = client.actor("v0iddo/zillow-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "locations": [
    "Austin, TX"
  ],
  "listingType": "for_sale",
  "maxItems": 20
};

const run = await client.actor('v0iddo/zillow-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~zillow-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"locations": ["Austin, TX"], "listingType": "for_sale", "maxItems": 20}'

Price

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Zillow shows at most about 820 listings (20 pages) per search. For a bigger area, run several ZIP codes or neighborhoods instead of one city.
  • Rental searches mostly return apartment buildings: those rows have a price range, the building name and a list of unit types in units, and no beds or baths of their own.
  • Sold prices are hidden by Zillow in states that do not disclose them (for example Texas); price is empty there.
  • lotArea is in square feet. Rows are unique by Zillow property ID across all searches of a run.

FAQ

What data does the Zillow Search Scraper return?

Each result is one row in an Apify dataset. Fields include address, priceText, beds, baths, livingArea, homeType, status, daysOnZillow, and more. The table above shows every field with an example value.

How do I use the Zillow Search Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/zillow-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
