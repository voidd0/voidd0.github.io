Screener.in Stock Fundamentals Scraper: how to get the data as JSON/CSV (API, Python, no code)

Scrape Indian listed company fundamentals from screener.in: market cap, P/E, ROCE, ROE, book value, dividend yield, 52-week high/low, and NSE/BSE codes for any ticker symbol. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/screener-in-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/screener-in-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'tickers': ['RELIANCE',
             'TCS',
             'INFY',
             'HDFCBANK',
             'ICICIBANK',
             'HINDUNILVR',
             'ITC',
             'SBIN',
             'BAJFINANCE',
             'WIPRO'],
 'consolidated': True,
 'maxItems': 20}

run = client.actor("v0iddo/screener-in-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "tickers": [
    "RELIANCE",
    "TCS",
    "INFY",
    "HDFCBANK",
    "ICICIBANK",
    "HINDUNILVR",
    "ITC",
    "SBIN",
    "BAJFINANCE",
    "WIPRO"
  ],
  "consolidated": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/screener-in-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~screener-in-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["RELIANCE", "TCS", "INFY", "HDFCBANK", "ICICIBANK", "HINDUNILVR", "ITC", "SBIN", "BAJFINANCE", "WIPRO"], "consolidated": true, "maxItems": 20}'

Price

$5.92 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $4.14 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers public company pages on screener.in for NSE and BSE listed Indian companies. Price data is delayed: BSE by 5 minutes, NSE by 15 minutes per screener.in.
  • If a ticker symbol is not found (404), that entry is skipped and logged. Verify symbols on screener.in before running bulk jobs.
  • The consolidated view is tried first when enabled; falls back to the standalone page automatically if no consolidated view exists for a ticker.
  • Not affiliated with screener.in (Mittal Analytics Private Ltd).

FAQ

What data does the Screener.in Stock Fundamentals Scraper return?

Each result is one row in an Apify dataset. Fields include ticker, name, currentPrice, marketCapCr, stockPE, roce, roe, bookValue, and more. The table above shows every field with an example value.

How do I use the Screener.in Stock Fundamentals Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/screener-in-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$5.92 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $4.14 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
