IrishJobs.ie and Jobs.ie Scraper: how to get Ireland Jobs and Salaries as JSON/CSV (API, Python, no code)

Scrape job postings from IrishJobs.ie and Jobs.ie in Ireland: title, company, town, county, salary in EUR with min, max and period, date posted, closing date and snippet; with details, contract, work mode, province, map point and full text. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/irishjobs-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "accountant"
  ],
  "location": "Dublin",
  "site": "irishjobs.ie",
  "includeDetails": false,
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayJob titles or words such as accountant, software engineer or nurse.
locationstringOptional Irish town or county such as Dublin, Cork, Galway or Limerick.
sitestringWhere the search terms are searched.
salaryOnlybooleanOnly postings that show a salary figure (not "Not Disclosed").
includeDetailsbooleanRead each posting's page for the contract type, work mode, employment type, industry, province, map point and the full description.
searchUrlsarrayIrishJobs.ie or Jobs.ie search result pages copied from your browser, for example https://www.irishjobs.ie/jobs/accountant/in-dublin .
jobUrlsarrayJob posting pages to read with every detail, one row each, for example https://www.irishjobs.ie/job/accountant/embassy-of-south-africa-job108231343 .
maxItemsintegerThe run stops after this many result rows.
onlyNewbooleanSkip rows that an earlier run with the same input already returned, so a scheduled run gives each new row once.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/irishjobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['accountant'],
 'location': 'Dublin',
 'site': 'irishjobs.ie',
 'includeDetails': False,
 'maxItems': 20}

run = client.actor("v0iddo/irishjobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "accountant"
  ],
  "location": "Dublin",
  "site": "irishjobs.ie",
  "includeDetails": false,
  "maxItems": 20
};

const run = await client.actor('v0iddo/irishjobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~irishjobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["accountant"], "location": "Dublin", "site": "irishjobs.ie", "includeDetails": false, "maxItems": 20}'

Good to know

  • One search runs per search term, on the board you chose and in the place you chose (both boards: each term twice). Pasted search URLs are read without their filter parameters. Postings are unique...
  • The boards widen a search with related job titles and nearby places and count them in their total: a search in Dublin also lists postings in Meath or Kildare.
  • salaryText is the salary as the posting shows it. salaryMin and salaryMax are its figures (40934 and 45463 for a band of 40,934 to 45,463 euro a year), salaryCurrency is EUR (GBP for pounds) and...
  • location is the place as the board shows it ("Dublin, County Dublin"); town and county are read from it, and countryCode from the county. With posting details on, province (Leinster, Munster...

FAQ

What data does the IrishJobs.ie and Jobs.ie Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, county, salaryText, salaryMin, salaryMax, salaryInterval, and more. The table above shows every field with an example value.

How do I use the IrishJobs.ie and Jobs.ie Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/irishjobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.23 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.86 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
