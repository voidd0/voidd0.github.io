Scrape Fotocasa property listings for sale or to rent across Spain: price, price drop, rooms, bathrooms, surface, floor, features, neighbourhood and city, coordinates, photos, agency and publication date. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/fotocasa-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "searchUrls": [
    "https://www.fotocasa.es/es/comprar/viviendas/madrid-capital/todas-las-zonas/l"
  ],
  "channel": "buy",
  "maxItems": 20
}
Input fieldTypeWhat it does
locationsarrayFotocasa place slugs such as madrid-capital, barcelona-capital or valencia-capital.
channelstringProperties for sale or to rent.
searchUrlsarraySearch result pages copied from your browser, for example https://www.fotocasa.es/es/alquiler/viviendas/valencia-capital/todas-las-zonas/l .
includeZonesbooleanFotocasa's robots.txt leaves only the first page of each search open to automated clients, about 30 listings.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/fotocasa-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchUrls': ['https://www.fotocasa.es/es/comprar/viviendas/madrid-capital/todas-las-zonas/l'],
 'channel': 'buy',
 'maxItems': 20}

run = client.actor("v0iddo/fotocasa-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchUrls": [
    "https://www.fotocasa.es/es/comprar/viviendas/madrid-capital/todas-las-zonas/l"
  ],
  "channel": "buy",
  "maxItems": 20
};

const run = await client.actor('v0iddo/fotocasa-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~fotocasa-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchUrls": ["https://www.fotocasa.es/es/comprar/viviendas/madrid-capital/todas-las-zonas/l"], "channel": "buy", "maxItems": 20}'

Good to know

  • Coverage: homes for sale and to rent on fotocasa.es. Fotocasa's robots.txt closes every results page after the first, so one search returns the first page, about 30 listings. A search of a whole...
  • Large zones are not read to the end. To go deeper, search smaller zones: add place slugs with a zone such as madrid-capital/chamberi, or paste the address of a district or neighbourhood page.
  • Telephone numbers and e-mail addresses are never collected, and any found inside an agency description are removed. Descriptions are clipped to about 300 characters.
  • Listings from private sellers are reduced to area level (no street, no map point, no description) so no private person can be identified. They carry sellerType private and no agency, name or...

FAQ

What data does the Fotocasa Scraper return?

Each result is one row in an Apify dataset. Fields include propertyId, address, price, rentPeriod, propertyType, rooms, bathrooms, surfaceM2, and more. The table above shows every field with an example value.

How do I use the Fotocasa Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/fotocasa-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
