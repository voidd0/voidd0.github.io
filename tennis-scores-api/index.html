Tennis Scores and Results Scraper: how to get ATP, WTA, Odds, Rankings as JSON/CSV (API, Python, no code)

Scrape tennis scores: ATP and WTA match results of any day with set by set scores, tiebreaks, winner and pre-match odds, the day's schedule, current WTA singles or doubles rankings, or the WTA season calendar. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/tennis-scores-api on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "dataType": "match_results",
  "matchType": "all",
  "days": 1,
  "maxItems": 20
}
Input fieldTypeWhat it does
dataTypestringmatchresults: finished matches of a day with set scores, winner and odds.
matchTypestringWhich matches to read: all (ATP and WTA, singles and doubles), atp-single, wta-single, atp-double or wta-double.
datestringDay to read as YYYY-MM-DD.
daysintegerNumber of days to read: matchresults goes back from Date, upcomingmatches goes forward from it.

maxPagesintegerNumber of ranking list pages to fetch.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/tennis-scores-api.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'dataType': 'match_results', 'matchType': 'all', 'days': 1, 'maxItems': 20}

run = client.actor("v0iddo/tennis-scores-api").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "dataType": "match_results",
  "matchType": "all",
  "days": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/tennis-scores-api').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~tennis-scores-api/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"dataType": "match_results", "matchType": "all", "days": 1, "maxItems": 20}'

Price

$1.95 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.36 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Match results (the default) list every finished ATP and WTA match of the day, Challenger events included, with the winner first: set by set games, a tiebreak as 7-6(5), sets won and the two...
  • Times are the site's (GMT+1, as tennisexplorer.com shows them); startTimeUtc gives the same start in UTC. Doubles rows name both players of each team. status is finished, retired, walkover...
  • Rankings (dataType wtarankings) cover active WTA tour professionals, about 20 players a page; the WTA calendar (wtatournaments) lists the season's events with start and end dates.
  • Data reflects what the sites publish at the time of collection; a match in progress is not followed live.

FAQ

What data does the Tennis Scores and Results Scraper return?

Each result is one row in an Apify dataset. Fields include date, time, tournamentName, player1, player2, score, winner, odds1, and more. The table above shows every field with an example value.

How do I use the Tennis Scores and Results Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/tennis-scores-api with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.95 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.36 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
