SEO audit tool: how to get on-page SEO data as JSON/CSV (API, Python, no code)

Audit the on-page SEO of any public web pages: title, meta description, headings, canonical, indexability, structured data types, image alt text, link counts and social tags, with a list of issues and a 0 to 100 score per page. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/seo-audit on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/seo-audit.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'startUrls': ['https://www.python.org/',
               'https://docs.python.org/3/',
               'https://www.joelonsoftware.com/'],
 'maxPagesPerSite': 5,
 'maxItems': 20}

run = client.actor("v0iddo/seo-audit").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "startUrls": [
    "https://www.python.org/",
    "https://docs.python.org/3/",
    "https://www.joelonsoftware.com/"
  ],
  "maxPagesPerSite": 5,
  "maxItems": 20
};

const run = await client.actor('v0iddo/seo-audit').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~seo-audit/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://www.python.org/", "https://docs.python.org/3/", "https://www.joelonsoftware.com/"], "maxPagesPerSite": 5, "maxItems": 20}'

Price

$4.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.80 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One row per audited page. At most 500 listed addresses, at most 200 pages per site and 5000 pages per run. With Pages per site at 1 only the pages you list are read.
  • The page is read as a visitor without JavaScript sees it, so a page that builds its title or links in the browser shows what the server sends. The run does not read sitemaps, images or other sites.
  • The score starts at 100 and loses 20 points per error, 8 per warning and 2 per notice, down to 0. A page that answers with an HTTP error or an empty page scores 0, and a page that is not HTML (a...
  • Duplicate title and duplicate description checks compare a page with the pages of the same site audited earlier in the run, so the later page of a pair carries the finding and names the first.

FAQ

What data does the SEO audit tool return?

Each result is one row in an Apify dataset. Fields include url, statusCode, score, indexable, title, titleLength, metaDescriptionLength, h1Count, and more. The table above shows every field with an example value.

How do I use the SEO audit tool from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/seo-audit with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$4.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.80 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
