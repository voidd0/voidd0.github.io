articleUrlsarrayLinks to news articles or blog posts, one per line, at most 1000.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/news-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'feedUrls': ['https://www.nasa.gov/news-release/feed/'],
 'maxArticlesPerFeed': 10,
 'maxItems': 20}

run = client.actor("v0iddo/news-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "feedUrls": [
    "https://www.nasa.gov/news-release/feed/"
  ],
  "maxArticlesPerFeed": 10,
  "maxItems": 20
};

const run = await client.actor('v0iddo/news-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~news-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"feedUrls": ["https://www.nasa.gov/news-release/feed/"], "maxArticlesPerFeed": 10, "maxItems": 20}'

Good to know

  • Give article links, feeds, or both: at most 1000 links and 50 feeds. Feeds and sitemaps are read for their newest links (25 per feed unless you change Articles per feed, at most 500); each article...
  • RSS 2.0, RSS 1.0, Atom, standard XML sitemaps and Google News sitemaps work, also gzip sitemaps. A sitemap index is followed one level down, into at most 3 of its sitemaps (news sitemaps first).
  • Published after skips articles whose date is known to be older. A feed entry is checked before its page is read, so old entries cost nothing.
  • Each article is read from its structured data first, then from its page meta tags, then from the page body. Fields a page does not show are empty instead of guessed. The text is the main article...

FAQ

What data does the News article scraper return?

Each result is one row in an Apify dataset. Fields include title, publishedAt, siteName, section, language, wordCount, paywalled, url, and more. The table above shows every field with an example value.

How do I use the News article scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/news-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
