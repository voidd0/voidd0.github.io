Eventbrite Event Data Scraper: how to get City, Dates, Ticket Prices as JSON/CSV (API, Python, no code)

Collect public Eventbrite events for any city or online: name, start and end, venue and city, online flag, ticket prices, organizer name, link and image. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/eventbrite-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "locations": [
    "ny--new-york"
  ],
  "maxItems": 20
}
Input fieldTypeWhat it does
locations (required)arrayEventbrite place slugs such as ny--new-york, united-kingdom--london or online, or full https://www.eventbrite.com/d/...
keywordstringOptional search word or phrase, for example jazz or startup networking.
startDatestringOptional first day as YYYY-MM-DD.
endDatestringOptional last day as YYYY-MM-DD.
includeDetailsbooleanCosts one extra page per such event, so the run is slower.
maxPagesintegerHow many result pages to read for each location.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/eventbrite-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'locations': ['ny--new-york'], 'maxItems': 20}

run = client.actor("v0iddo/eventbrite-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "locations": [
    "ny--new-york"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/eventbrite-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~eventbrite-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"locations": ["ny--new-york"], "maxItems": 20}'

Price

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Browse pages (a place with no keyword) list about 40 events. Add a keyword or dates, or more places, for more.
  • Listings rarely show price or organizer, so with Fill in price and organizer on (the default) each event without them costs one extra page read, about one more second per event.
  • Price fields stay empty when an event page does not state them (for example tickets sold elsewhere). Only the organizer's name is read, never organizer pages or profiles. Events on other country...
  • Times are the event's local time (timezone field). Cancelled events are skipped.

FAQ

What data does the Eventbrite Event Data Scraper return?

Each result is one row in an Apify dataset. Fields include name, start, end, venueName, city, isOnline, isFree, priceMin, and more. The table above shows every field with an example value.

How do I use the Eventbrite Event Data Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/eventbrite-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
