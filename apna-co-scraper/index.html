Input fieldTypeWhat it does
keywordsarrayJob titles as the site names them, such as delivery boy, telecaller, accountant, data entry, sales or python developer, one per line.
citiesarrayCities such as Mumbai, Bengaluru, Delhi, Gurgaon, Hyderabad, Chennai, Pune or Kolkata, one per line (Bangalore, Bombay and the other old names work too).
departmentsarrayOptional. Only jobs of these departments of the site; empty means all.
workModesarrayOptional. Only work from home, work from office or field jobs; empty means all.
workTypesarrayOptional. Only full time or part time jobs; empty means both.
shiftsarrayOptional. Only day shift or night shift jobs; empty means both.
minSalaryintegerOnly jobs that pay at least this much a month, as the site's salary filter.
experienceYearsintegerOptional. Only jobs open to a candidate with this many years of experience, as the site's experience filter (0 for freshers).
educationstringOnly jobs open to a candidate with this education, as the site's filter.
postedWithinstringOnly jobs posted in that period.
sortBystringThe order of the site's listing: its own, highest salary first or newest first.
jobPagesbooleanOff: one request reads 25 jobs with the columns the listing shows.
cityJobsOnlybooleanThe site goes on with jobs of other cities of the same state once a city's own jobs run out (Pune and Nashik after Mumbai).
jobsPerSearchintegerOptional cap for each search (job title and city), so one search does not use the whole run.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/apna-co-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['delivery boy'], 'cities': ['Mumbai'], 'maxItems': 20}

run = client.actor("v0iddo/apna-co-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "delivery boy"
  ],
  "cities": [
    "Mumbai"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/apna-co-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~apna-co-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["delivery boy"], "cities": ["Mumbai"], "maxItems": 20}'

FAQ

What data does the Apna.co Scraper return?

Each result is one row in an Apify dataset. Fields include title, companyName, city, location, salaryMin, salaryMax, workMode, workType, and more. The table above shows every field with an example value.

How do I use the Apna.co Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/apna-co-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.78 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.55 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
