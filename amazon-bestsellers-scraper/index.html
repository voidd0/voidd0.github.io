Amazon Bestsellers Scraper: how to get New Releases as JSON/CSV (API, Python, no code)

Scrape Amazon.com Best Sellers and New Releases lists by category link: rank, ASIN, title, price, star rating, ratings count, image and product link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/amazon-bestsellers-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/amazon-bestsellers-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categoryUrls': ['https://www.amazon.com/gp/bestsellers/electronics'],
 'maxPages': 1,
 'maxItems': 20}

run = client.actor("v0iddo/amazon-bestsellers-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categoryUrls": [
    "https://www.amazon.com/gp/bestsellers/electronics"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/amazon-bestsellers-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~amazon-bestsellers-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categoryUrls": ["https://www.amazon.com/gp/bestsellers/electronics"], "maxPages": 1, "maxItems": 20}'

Price

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers amazon.com (United States). Amazon prints 30 ranked products per list page, so one list gives ranks 1 to 30 and 51 to 80 with full details; switch on the rank-gap option to also get ranks...
  • Pick a category or sub-category link. The all-departments Best Sellers page has no product list.
  • Amazon refreshes these lists about every hour, so ranks change between runs.
  • Best Sellers and New Releases are offered. Movers and Shakers and Most Wished For are not: Amazon shows them empty to visitors without an account.

FAQ

What data does the Amazon Bestsellers Scraper return?

Each result is one row in an Apify dataset. Fields include rank, asin, title, price, rating, ratingsCount, category, listType, and more. The table above shows every field with an example value.

How do I use the Amazon Bestsellers Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/amazon-bestsellers-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
