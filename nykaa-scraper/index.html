Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/nykaa-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categoryUrls': ['https://www.nykaa.com/makeup/eyes/c/14'],
 'maxPages': 1,
 'maxItems': 20}

run = client.actor("v0iddo/nykaa-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categoryUrls": [
    "https://www.nykaa.com/makeup/eyes/c/14"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/nykaa-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~nykaa-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categoryUrls": ["https://www.nykaa.com/makeup/eyes/c/14"], "maxPages": 1, "maxItems": 20}'

Good to know

  • Covers nykaa.com category listing pages in India. Paste any Nykaa category URL, for example https://www.nykaa.com/makeup/eyes/c/14 or https://www.nykaa.com/skin/moisturizers-and-creams/c/42.
  • Each page holds about 20 products; use maxPages to control depth. Large categories can have 100 or more pages.
  • Prices are in Indian Rupees (INR) as shown to anonymous visitors without an account.

FAQ

What data does the Nykaa Scraper return?

Each result is one row in an Apify dataset. Fields include productId, name, brand, category, price, mrp, discountPercent, rating, and more. The table above shows every field with an example value.

How do I use the Nykaa Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/nykaa-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$4.01 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.81 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
