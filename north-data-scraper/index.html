North Data Scraper: how to get the data as JSON/CSV (API, Python, no code)

Extract European company profiles from northdata.com: company name, register number, court, LEI code, address, founding date, corporate purpose, and officer count. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/north-data-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/north-data-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'companyUrls': ['https://www.northdata.com/BMW-AG,+M%C3%BCnchen/HRB+42243',
                 'https://www.northdata.com/Volkswagen+AG,+Wolfsburg/HRB+100484',
                 'https://www.northdata.com/Siemens+AG,+M%C3%BCnchen/HRB+6684',
                 'https://www.northdata.com/Deutsche+Telekom+AG,+Bonn/HRB+6794',
                 'https://www.northdata.com/BASF+SE,+Ludwigshafen+am+Rhein/HRB+6729',
                 'https://www.northdata.com/Bayer+AG,+Leverkusen/HRB+48248',
                 'https://www.northdata.com/Allianz+SE,+M%C3%BCnchen/HRB+164232',
                 'https://www.northdata.com/SAP+SE,+Walldorf/HRB+755676',
                 'https://www.northdata.com/Mercedes-Benz+Group+AG,+Stuttgart/HRB+19360',
                 'https://www.northdata.com/Deutsche+Bank+AG,+Frankfurt+am+Main/HRB+30000'],
 'maxItems': 20}

run = client.actor("v0iddo/north-data-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

Price

Good to know

  • Each northdata.com company profile URL yields one output row with public register data, LEI code, address, founding date, and officer count.
  • Officer names are not collected; only the total count of listed officers is included.
  • North Data covers companies in Germany, Austria, Switzerland, the United Kingdom, France, and more than 20 other European countries.
  • Not affiliated with North Data GmbH or northdata.com.

FAQ

What data does the North Data Scraper return?

Each result is one row in an Apify dataset. Fields include name, registerNumber, registerCourt, leiCode, street, city, postalCode, country, and more. The table above shows every field with an example value.

How do I use the North Data Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/north-data-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.98 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.09 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
