Currency exchange rates (ECB): how to get exchange rates as JSON/CSV (API, Python, no code)

Latest and historical euro foreign exchange reference rates from the European Central Bank, with conversion between any two of its currencies. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/currency-exchange-rates on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/currency-exchange-rates.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'op': 'convert', 'amount': '100', 'from': 'EUR', 'to': 'USD', 'date': '2026-01-02'}

run = client.actor("v0iddo/currency-exchange-rates").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "op": "convert",
  "amount": "100",
  "from": "EUR",
  "to": "USD",
  "date": "2026-01-02"
};

const run = await client.actor('v0iddo/currency-exchange-rates').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~currency-exchange-rates/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"op": "convert", "amount": "100", "from": "EUR", "to": "USD", "date": "2026-01-02"}'

FAQ

What data does the Currency exchange rates (ECB) return?

Each result is one row in an Apify dataset. Fields include index, amount, from, to, rate, result, date_used, source, and more. The table above shows every field with an example value.

How do I use the Currency exchange rates (ECB) from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/currency-exchange-rates with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.
