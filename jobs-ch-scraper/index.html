This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/jobs-ch-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/jobs-ch-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['data analyst'],
 'location': 'Zürich',
 'site': 'jobs.ch',
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/jobs-ch-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "data analyst"
  ],
  "location": "Zürich",
  "site": "jobs.ch",
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/jobs-ch-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~jobs-ch-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["data analyst"], "location": "Zürich", "site": "jobs.ch", "includeDetails": true, "maxItems": 20}'

Price

$0.90 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.63 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per search term on the chosen board (both boards: each term twice). Pasted search URLs keep their own filters. Postings are unique by ID across the whole run.
  • A search shows at most 100 pages of 20 postings. For a broad search, add a place or split it into several terms.
  • workload is the percent the posting names, such as 80-100% (workloadMin and workloadMax as numbers). employmentType is the first of employmentTypes: permanent, temporary, freelance, internship...
  • postedAt is the latest publication date, firstPostedAt the first one; a reposted job keeps its first date. Posted within days filters on postedAt.

FAQ

What data does the Jobs.ch & Jobup.ch Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, place, canton, workload, employmentType, position, postedAt, and more. The table above shows every field with an example value.

How do I use the Jobs.ch & Jobup.ch Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/jobs-ch-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.90 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.63 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
