Domain Availability Checker: how to get Bulk RDAP as JSON/CSV (API, Python, no code)

Check if domains are available, in bulk: one row per domain with available or registered, registrar, creation and expiry dates and days to expiry, straight from the registry that runs the TLD (RDAP). This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/domain-availability-checker on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/domain-availability-checker.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'domains': ['google.com',
             'github.com',
             'wikipedia.org',
             'python.org',
             'mozilla.org',
             'voiddo.com',
             'bbc.co.uk',
             'example.net',
             'voiddo-availability-sample-7q3.com',
             'voiddo-availability-sample-7q3.org',
             'shop.github.com'],
 'maxItems': 20}

run = client.actor("v0iddo/domain-availability-checker").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "domains": [
    "google.com",
    "github.com",
    "wikipedia.org",
    "python.org",
    "mozilla.org",
    "voiddo.com",
    "bbc.co.uk",
    "example.net",
    "voiddo-availability-sample-7q3.com",
    "voiddo-availability-sample-7q3.org",
    "shop.github.com"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/domain-availability-checker').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~domain-availability-checker/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["google.com", "github.com", "wikipedia.org", "python.org", "mozilla.org", "voiddo.com", "bbc.co.uk", "example.net", "voiddo-availability-sample-7q3.com", "voiddo-availability-sample-7q3.org", "shop.github.com"], "maxItems": 20}'

Price

Good to know

  • Available means not registered at the registry. A reserved or premium name can still be refused or cost more at a registrar.
  • A TLD without an RDAP service, or a registry that closes its RDAP service in robots.txt, gives status unknown with the reason. No guessing from DNS.
  • A name under a registered domain (shop.example.com) gives status subdomain: it cannot be registered on its own.
  • Answered: .com, .net, .org, .app, .dev, .page, .info, .biz, .club, .fr, .nl, .ca, .au and every other extension whose registry runs an open RDAP service. Not answered (status unknown): .io, .de...

FAQ

What data does the Domain Availability Checker return?

Each result is one row in an Apify dataset. Fields include domain, available, status, registrar, expirationDate, daysToExpiry, registrationDate, note, and more. The table above shows every field with an example value.

How do I use the Domain Availability Checker from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/domain-availability-checker with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
