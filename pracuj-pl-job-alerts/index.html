Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/pracuj-pl-job-alerts.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['księgowa'],
 'location': 'Warszawa',
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/pracuj-pl-job-alerts").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "księgowa"
  ],
  "location": "Warszawa",
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/pracuj-pl-job-alerts').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~pracuj-pl-job-alerts/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["księgowa"], "location": "Warszawa", "includeDetails": true, "maxItems": 20}'

Good to know

  • Each run compares the offers it finds with the list the last run of the same watch saved, and returns only the changes: NEW for an offer no earlier run returned, UPDATED when its title, company...
  • A watch is the State key, or without one the search fields. The first run of a watch returns the offers it finds as NEW, up to Maximum results; an offer a run found but did not return comes as NEW...
  • Offers are reported as EXPIRED only after a run that checked every offer of the searches: keep Offers checked per run above the number they list. A run in which pracuj.pl lists no offer at all...
  • The list of known offers is one record per watch in the store state-pracuj-pl-job-alerts in your own Apify account. When it cannot be read, the run stops before reading any page, charges nothing...

FAQ

What data does the Pracuj.pl Job Alerts return?

Each result is one row in an Apify dataset. Fields include changeType, title, company, location, salaryText, workModes, changedFields, firstSeenAt, and more. The table above shows every field with an example value.

How do I use the Pracuj.pl Job Alerts from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/pracuj-pl-job-alerts with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.00 per 1,000 results. You pay per result row. The Actor also charges $0.002 per alert delivered, $0.010 per monitor run. Higher Apify plans pay less per result, down to $1.40 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
