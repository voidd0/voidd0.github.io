Gupy Jobs Scraper: how to get Brazil Job Vacancies as JSON/CSV (API, Python, no code)

Scrape Brazilian job postings from Gupy, the hiring system of most large employers in Brazil: title, company, city, state, job type, remote or hybrid, posted and deadline dates, requirements, hiring steps and the reason for the opening. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/gupy-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "analista de dados"
  ],
  "state": "São Paulo",
  "includeDetails": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayJob titles or words such as analista, desenvolvedor or vendedor.
statestringOnly postings in this Brazilian state.
citystringOnly postings in this city, written as on Gupy, for example Campinas or Belo Horizonte.
workplaceTypesarrayOnly these work modes. Leave empty for all.
jobTypesarrayOnly these job types. Leave empty for all.
companiesarrayOnly postings of these employers, by the name their Gupy career page shows, for example Stefanini Group or Raízen.
pwdOnlybooleanOnly postings marked as open to people with disabilities (PcD).
postedWithinstringOnly postings published in that period.
includeDetailsbooleanRead each posting's page for the description, responsibilities, requirements and nice to have as separate texts, the full address, the hiring steps, the reason for the...
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/gupy-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['analista de dados'],
 'state': 'São Paulo',
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/gupy-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "analista de dados"
  ],
  "state": "São Paulo",
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/gupy-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~gupy-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["analista de dados"], "state": "São Paulo", "includeDetails": true, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per search term, job type, work mode and company you chose, with the state, city and disability filters on each. Postings are unique by ID across the whole run, newest first.
  • company is the name of the employer's Gupy career page as the search shows it, which some employers fill with a slogan; companySubdomain is the career site's address (ccl for ccl.gupy.io) and...
  • jobType is Gupy's job type (effective, internship, legalentity ...) and jobTypeLabel its Portuguese label. hiringReason is staffincrease (a new position) or staff_replacement, as the employer...
  • descriptionText, responsibilities, requirements and niceToHave are the posting's own sections in Portuguese with details on; with details off descriptionText is the search's text of the posting...

FAQ

What data does the Gupy Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, city, state, jobTypeLabel, workplaceType, hiringReason, publishedAt, and more. The table above shows every field with an example value.

How do I use the Gupy Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/gupy-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
