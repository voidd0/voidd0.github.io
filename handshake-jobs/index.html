Scrape open job postings from joinhandshake.com into structured rows: title, department, employment type, location, workplace type, compensation, published date, description, and application link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/handshake-jobs on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/handshake-jobs.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keyword': '', 'employmentType': '', 'workplaceType': '', 'maxItems': 20}

run = client.actor("v0iddo/handshake-jobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keyword": "",
  "employmentType": "",
  "workplaceType": "",
  "maxItems": 20
};

const run = await client.actor('v0iddo/handshake-jobs').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~handshake-jobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keyword": "", "employmentType": "", "workplaceType": "", "maxItems": 20}'

Good to know

  • Returns job postings from the joinhandshake.com company careers page (roles at the Handshake company itself). All listings are delivered in a single page request; keyword and type filters are...
  • Compensation is displayed only when the employer has enabled salary transparency; compensationSummary will be null for postings where it is not shown.
  • Employment types present in the data: FullTime, Contract. Workplace types: Remote, OnSite, Hybrid.
  • Not affiliated with Handshake.

FAQ

What data does the Handshake Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include jobId, title, department, employmentType, workplaceType, location, isRemote, publishedAt, and more. The table above shows every field with an example value.

How do I use the Handshake Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/handshake-jobs with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.85 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.59 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
