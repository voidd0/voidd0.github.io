Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/y-combinator-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'companyUrls': ['https://www.ycombinator.com/companies/stripe',
                 'https://www.ycombinator.com/companies/airbnb',
                 'https://www.ycombinator.com/companies/dropbox',
                 'https://www.ycombinator.com/companies/reddit',
                 'https://www.ycombinator.com/companies/doordash',
                 'https://www.ycombinator.com/companies/coinbase',
                 'https://www.ycombinator.com/companies/instacart',
                 'https://www.ycombinator.com/companies/gitlab',
                 'https://www.ycombinator.com/companies/gusto',
                 'https://www.ycombinator.com/companies/brex',
                 'https://www.ycombinator.com/companies/openai',
                 'https://www.ycombinator.com/companies/figma'],
 'maxItems': 20}

run = client.actor("v0iddo/y-combinator-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "companyUrls": [
    "https://www.ycombinator.com/companies/stripe",
    "https://www.ycombinator.com/companies/airbnb",
    "https://www.ycombinator.com/companies/dropbox",
    "https://www.ycombinator.com/companies/reddit",
    "https://www.ycombinator.com/companies/doordash",
    "https://www.ycombinator.com/companies/coinbase",

    "https://www.ycombinator.com/companies/gitlab",
    "https://www.ycombinator.com/companies/gusto",
    "https://www.ycombinator.com/companies/brex",
    "https://www.ycombinator.com/companies/openai",
    "https://www.ycombinator.com/companies/figma"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/y-combinator-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

Price

Good to know

  • Reads individual YC company profile pages at ycombinator.com/companies/. Filtered directory pages (by batch, industry, etc.) are closed in robots.txt and are never requested; provide explicit...
  • Each input must be a ycombinator.com/companies/ URL or a bare slug such as stripe or airbnb.
  • Team size and open job count reflect what the public YC profile shows at scrape time and may lag behind current reality.
  • Not affiliated with Y Combinator.

FAQ

What data does the Y Combinator Company Directory Scraper return?

Each result is one row in an Apify dataset. Fields include name, batch, status, industries, location, website, oneLiner, teamSize, and more. The table above shows every field with an example value.

How do I use the Y Combinator Company Directory Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/y-combinator-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.92 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.04 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
