Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "finance manager"
  ],
  "locations": [
    "Mumbai"
  ],
  "includeDetails": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayJob titles, skills or words such as chartered accountant, product manager or brand manager.
categorystringOptional. With search terms it keeps the results of this category; alone it lists the category, for example Banking & Finance or Consulting.
locationsarrayOptional cities or states such as Bangalore, Mumbai, Delhi NCR, Pune, Hyderabad, Chennai or Remote.
experienceMinintegerOptional. Postings whose experience band overlaps the range you give.
experienceMaxintegerOptional. Upper end of the experience range in years.
postedWithinstringOnly postings from the last 3, 7, 15 or 30 days.
salaryOnlybooleanKeep only postings whose employer shows the salary range.
remoteOnlybooleanKeep only postings marked work from home or located in Remote.
includeDetailsbooleanRead each posting once more for its description text.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/iimjobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['finance manager'],
 'locations': ['Mumbai'],
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/iimjobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "finance manager"
  ],
  "locations": [
    "Mumbai"
  ],
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/iimjobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~iimjobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["finance manager"], "locations": ["Mumbai"], "includeDetails": true, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per search term; postings are unique by ID across the whole run. Without search terms, a category lists every open posting of that category on iimjobs.com.
  • A search shows at most 100 pages of 50 postings. For a broad search, add locations or an experience range.
  • salaryMinLakhs and salaryMaxLakhs are the yearly salary in lakhs of rupees (1 lakh = 100,000 INR), only when the employer shows it; salaryHidden is true otherwise. Most employers hide it.
  • experienceMin and experienceMax are the years of experience the posting asks for. The experience filter keeps postings whose band overlaps your range.

FAQ

What data does the IIMJobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, experienceMin, experienceMax, salaryMinLakhs, salaryMaxLakhs, skills, and more. The table above shows every field with an example value.

How do I use the IIMJobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/iimjobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
