eBay Scraper: how to get Category Listings, Prices, Sold and Watchers as JSON/CSV (API, Python, no code)

Collect listings from eBay category pages: title, price with currency, condition, shipping, sold and watcher counts, bids when shown, photo and link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/ebay-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/ebay-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categoryUrls': ['https://www.ebay.com/b/Cell-Phones-Smartphones/9355/bn_320094'],
 'maxItems': 20}

run = client.actor("v0iddo/ebay-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categoryUrls": [
    "https://www.ebay.com/b/Cell-Phones-Smartphones/9355/bn_320094"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/ebay-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~ebay-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categoryUrls": ["https://www.ebay.com/b/Cell-Phones-Smartphones/9355/bn_320094"], "maxItems": 20}'

Price

$2.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.40 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each category link gives the first page of results, about 60 items. eBay's robots.txt closes page numbers, filters and search, so for more rows give more category links or switch on related...
  • Some cards are catalog products rather than single listings (cardType product): their price can be a range (price is the low end, priceMax the high end) and the link points to a representative...
  • Bids, buying format, time left and location are filled only when the card shows them; many cards do not. Brand is the second part of the condition line as eBay prints it.
  • Sellers are never collected: no names, feedback or profile links. Only eBay program badges such as eBay Refurbished are kept.

FAQ

What data does the eBay Scraper return?

Each result is one row in an Apify dataset. Fields include title, price, currency, priceText, previousPrice, condition, brand, shippingText, and more. The table above shows every field with an example value.

How do I use the eBay Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/ebay-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.40 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
