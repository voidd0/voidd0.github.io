Input fieldTypeWhat it does
keywordsarrayJob titles or words such as python, java developer, ksiegowa or kierowca, one per line (Polish letters work).
locationstringOptional city such as Warszawa, Krakow, Wroclaw, Gdansk or Poznan (Warsaw and Polish letters work too), or remote for remote jobs.
sourcesarrayThe boards to search; all four by default.
contractTypesarrayOptional. Only jobs with one of these contracts; empty means all.
salaryOnlybooleanOnly jobs that show a salary range: each board's own With salary filter, and RocketJobs.pl jobs without a salary left out.
includeDetailsbooleanPracuj.pl jobs get their category, skills and gross or net from the job's own page: one more request per Pracuj.pl job, so slower.
maxItemsintegerThe run stops after this many result rows.
onlyNewbooleanSkip rows that an earlier run with the same input, or with the same State key, already returned, so a scheduled run gives each new row once, with isNew true and firstS...
stateKeystringOptional, with Only new results: a name for the list of rows already returned.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/poland-jobs-feed.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['python'], 'maxItems': 20}

run = client.actor("v0iddo/poland-jobs-feed").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "python"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/poland-jobs-feed').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~poland-jobs-feed/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["python"], "maxItems": 20}'

Good to know

  • Each search term runs on every board you pick, in the city you chose. The run takes one job from each board in turn, so a small Maximum results still shows every board.
  • A job listed on two boards, or twice on one, comes once: the first board that gave it keeps it. Two jobs are the same when their title, company and city match once written alike (Polish letters...
  • salaryMin, salaryMax, salaryCurrency, salaryInterval (month, day, hour or year) and salaryType (gross or net, as the board says) are the employer's own figures as each board shows them.
  • contractTypes are in English: employment contract (UoP), B2B, mandate contract (UZ), contract for specific work (UoD) and internship. RocketJobs.pl states a job's type as full time, part time...

FAQ

What data does the Poland Jobs Feed return?

Each result is one row in an Apify dataset. Fields include title, company, city, source, salaryMin, salaryMax, salaryCurrency, salaryInterval, and more. The table above shows every field with an example value.

How do I use the Poland Jobs Feed from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/poland-jobs-feed with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.00 per 1,000 results. You pay per result row. The Actor also charges $0.010 per actor start. Higher Apify plans pay less per result, down to $1.40 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
