Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/djinni-co-job-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'primaryKeyword': 'Python', 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/djinni-co-job-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "primaryKeyword": "Python",
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/djinni-co-job-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~djinni-co-job-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"primaryKeyword": "Python", "maxPages": 1, "maxItems": 20}'

Good to know

  • Covers djinni.co, a Ukrainian IT job board focused on remote-first tech vacancies for Ukraine and Europe. The site lists over 5000 open positions.
  • Each listing page returns up to 15 jobs. Increase maxPages to collect more results. Popular keywords such as Python or React return hundreds of listings.
  • Salary fields are populated only when the employer disclosed a range; many listings omit salary.

FAQ

What data does the Djinni.co Job Scraper return?

Each result is one row in an Apify dataset. Fields include jobId, title, companyName, category, employmentType, salaryMin, salaryMax, experienceMonths, and more. The table above shows every field with an example value.

How do I use the Djinni.co Job Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/djinni-co-job-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.81 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.57 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
