Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "engineer",
    "designer"
  ],
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarraySearch keywords such as 'engineer', 'product manager', or 'designer'.
remoteOnlybooleanWhen enabled, only remote-eligible jobs are returned.
ycBatchstringFilter results to a single YC batch, for example W24 or S23.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/ycombinator-was-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['engineer', 'designer'], 'maxItems': 20}

run = client.actor("v0iddo/ycombinator-was-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "engineer",
    "designer"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/ycombinator-was-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~ycombinator-was-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["engineer", "designer"], "maxItems": 20}'

Price

$2.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.40 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each keyword triggers one request to ycombinator.com/jobs; each page returns roughly 20 listings. Use multiple keywords to widen coverage, up to 20 keywords per run.
  • The YC batch filter and remote filter are applied after the page is fetched; they do not change which listings the site returns.
  • Salary and equity data are included only when the company provides them in the listing.
  • Not affiliated with Y Combinator.

FAQ

What data does the Y Combinator Work at a Startup Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include jobId, jobTitle, jobUrl, companyName, ycBatch, salaryRange, equityRange, location, and more. The table above shows every field with an example value.

How do I use the Y Combinator Work at a Startup Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/ycombinator-was-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.40 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
