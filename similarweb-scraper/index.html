Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/similarweb-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categorySlugs': ['',
                   'computers-electronics-and-technology',
                   'arts-and-entertainment'],
 'maxItems': 20}

run = client.actor("v0iddo/similarweb-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categorySlugs": [
    "",
    "computers-electronics-and-technology",
    "arts-and-entertainment"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/similarweb-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~similarweb-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categorySlugs": ["", "computers-electronics-and-technology", "arts-and-entertainment"], "maxItems": 20}'

Price

$1.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.19 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each Similarweb category page lists up to 50 ranked websites. Use an empty string in categorySlugs to get the global top 50.
  • rankingList names the ranking each row comes from: the category slug you asked for, or global for the global top 50. categorySlug is the site's own category, which is often a subcategory of the list.
  • Rankings are updated monthly by Similarweb and reflect the previous calendar month.
  • Bounce rate, pages per visit, and visit duration may be unavailable for some entries.

FAQ

What data does the Similarweb Scraper return?

Each result is one row in an Apify dataset. Fields include rank, domain, category, categorySlug, rankChange, avgVisitDuration, avgVisitDurationSeconds, pagesPerVisit, and more. The table above shows every field with an example value.

How do I use the Similarweb Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/similarweb-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.19 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
