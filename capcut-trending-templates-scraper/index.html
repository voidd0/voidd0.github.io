maxPagesintegerResult pages to read per category (about 20 templates per page, max 10 pages).
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/capcut-trending-templates-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categories': ['editors-pick'], 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/capcut-trending-templates-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categories": [
    "editors-pick"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/capcut-trending-templates-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~capcut-trending-templates-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categories": ["editors-pick"], "maxPages": 1, "maxItems": 20}'

Price

$1.61 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.13 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers capcut.com public template category pages. Known slugs include editors-pick, birthday, travel, food, fashion, beauty, music, sports, and wedding; browse capcut.com/template for the full list.
  • Individual template share pages (/t/...) are closed by robots.txt and are not fetched; templateUrl links to each template detail page.
  • Use count reflects values shown to any visitor without an account and updates continuously; re-run regularly to track trending velocity.
  • Not affiliated with CapCut or its parent company.

FAQ

What data does the CapCut Trending Templates Scraper return?

Each result is one row in an Apify dataset. Fields include templateId, title, category, useCount, likeCount, durationMs, description, coverImageUrl, and more. The table above shows every field with an example value.

How do I use the CapCut Trending Templates Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/capcut-trending-templates-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.61 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.13 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
