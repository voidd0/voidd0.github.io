Reed Jobs Scraper: how to get UK Jobs and Salaries as JSON/CSV (API, Python, no code)

Scrape UK job postings from reed.co.uk: title, company, agency or employer, place, county, region, postcode, salary range with the period, job type, full or part time, remote or hybrid, posting and expiry dates, sector, skills and the description. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/reed-jobs-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "data analyst"
  ],
  "location": "London",
  "includeDetails": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayJob titles or words such as data analyst, HGV driver or nurse.
locationstringOptional town, city, county or postcode such as Manchester, Kent or SW1A.
distanceMilesintegerHow far from the place postings may be, 0 to 100 miles.
postedWithinstringOnly postings published in that period.
jobTypesarrayOptional. Only these job types; empty means all.
hoursstringFull time or part time postings only.
workingOptionstringRemote, hybrid or on site postings only.
advertiserstringPostings by employers directly or by recruitment agencies only.
minimumSalaryintegerOptional. Reed's own salary filter, by the yearly equivalent.
searchUrlsarraySearch result pages copied from your browser, for example https://www.reed.co.uk/jobs/data-analyst-jobs-in-london?proximity=5 .
includeDetailsbooleanRead each posting's page for the description text, contract type, sector, region, postcode, the salary as shown and the skill tags.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/reed-jobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['data analyst'],
 'location': 'London',
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/reed-jobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "data analyst"
  ],
  "location": "London",
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/reed-jobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~reed-jobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["data analyst"], "location": "London", "includeDetails": true, "maxItems": 20}'

FAQ

What data does the Reed Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, advertiser, location, salaryText, jobType, workingOption, postedAt, and more. The table above shows every field with an example value.

How do I use the Reed Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/reed-jobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.45 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.32 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
