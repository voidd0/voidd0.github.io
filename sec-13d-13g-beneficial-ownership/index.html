Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/sec-13d-13g-beneficial-ownership.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'cik': ['0000320193', '0001318605', '0001067983']}

run = client.actor("v0iddo/sec-13d-13g-beneficial-ownership").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "cik": [
    "0000320193",
    "0001318605",
    "0001067983"
  ]
};

const run = await client.actor('v0iddo/sec-13d-13g-beneficial-ownership').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~sec-13d-13g-beneficial-ownership/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"cik": ["0000320193", "0001318605", "0001067983"]}'
