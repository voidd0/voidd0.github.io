elempleo Scraper: how to get Colombia Jobs and Salaries as JSON/CSV (API, Python, no code)

Scrape job postings from elempleo.com, Colombia's second largest job board: title, company, city, salary band in COP with min and max, contract, work mode, tags and description; with details, region, dates, education, experience and schedule. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/elempleo-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "contador"
  ],
  "location": "Bogotá",
  "includeDetails": false,
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayJob titles or words such as contador, auxiliar contable or desarrollador.
locationstringOptional Colombian city such as Bogotá, Medellín, Cali or Barranquilla.
salaryOnlybooleanOnly postings that show a salary band (not "Salario confidencial").
includeDetailsbooleanRead each posting's page for the region, date posted, valid through date, employment type, education, experience, schedule, job level, profession, sectors, openings an...
searchUrlsarrayelempleo search result pages copied from your browser, for example https://www.elempleo.com/co/ofertas-empleo/bogota/trabajo-contador .
jobUrlsarrayJob posting pages to read with every detail, one row each, for example https://www.elempleo.com/co/ofertas-trabajo/contador-administrativo-1886769841 .
maxItemsintegerThe run stops after this many result rows.
onlyNewbooleanSkip rows that an earlier run with the same input already returned, so a scheduled run gives each new row once.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/elempleo-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['contador'],
 'location': 'Bogotá',
 'includeDetails': False,
 'maxItems': 20}

run = client.actor("v0iddo/elempleo-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "contador"
  ],
  "location": "Bogotá",
  "includeDetails": false,
  "maxItems": 20
};

const run = await client.actor('v0iddo/elempleo-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~elempleo-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["contador"], "location": "Bogotá", "includeDetails": false, "maxItems": 20}'

FAQ

What data does the elempleo Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, city, salaryText, salaryMin, salaryMax, contractType, workMode, and more. The table above shows every field with an example value.

How do I use the elempleo Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/elempleo-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.85 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.59 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
