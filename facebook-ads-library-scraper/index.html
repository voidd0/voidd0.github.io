Facebook Ad Library scraper: how to get ads as JSON/CSV (API, Python, no code)

Collect public ads from the Meta Ad Library by keyword, advertiser Page ID or Ad Library link: ad text, headline, landing page, button, images and videos, dates, platforms and version count, plus spend and reach ranges where Meta publishes them. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/facebook-ads-library-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "searchTerms": [
    "nike"
  ],
  "country": "US",
  "activeStatus": "active",
  "maxItems": 20
}
Input fieldTypeWhat it does
searchTermsarrayWords to search the Ad Library for, for example a brand or product name.
pageIdsarrayNumeric Facebook Page IDs of advertisers whose ads you want, one per line.
adLibraryUrlsarrayOptional search links copied from the browser, such as https://www.facebook.com/ads/library/?activestatus=active&adtype=all&country=US&q=nike&searchtype=keywordunordered.
countrystringWhere the ads were shown: a two-letter country code such as US, GB or DE, or ALL for every country.
activeStatusstringWhich ads to return: ads that are running now, ads that stopped, or both.
adTypestringAd category in the Ad Library.
mediaTypestringOnly ads that contain this kind of media.
startDateMinstringOptional. Only ads that started running on or after this date, as YYYY-MM-DD.
startDateMaxstringOptional. Only ads that started running on or before this date, as YYYY-MM-DD.
maxAdsPerSearchintegerThe most ads to read for each search term, Page ID or link.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/facebook-ads-library-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchTerms': ['nike'], 'country': 'US', 'activeStatus': 'active', 'maxItems': 20}

run = client.actor("v0iddo/facebook-ads-library-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchTerms": [
    "nike"
  ],
  "country": "US",
  "activeStatus": "active",
  "maxItems": 20
};

const run = await client.actor('v0iddo/facebook-ads-library-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~facebook-ads-library-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["nike"], "country": "US", "activeStatus": "active", "maxItems": 20}'

FAQ

What data does the Facebook Ad Library scraper return?

Each result is one row in an Apify dataset. Fields include adArchiveId, pageName, isActive, startDate, endDate, platforms, body, title, and more. The table above shows every field with an example value.

How do I use the Facebook Ad Library scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/facebook-ads-library-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
