Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "publications": [
    "on.substack.com"
  ],
  "maxItems": 20
}
Input fieldTypeWhat it does
publications (required)arrayPublication addresses such as https://on.substack.com or https://www.lennysnewsletter.com, or just the name before .substack.com (on).
maxPostsPerPublicationintegerHow many posts to collect from each publication.
sortBystringOrder in which the posts are read.
keywordstringOptional word or phrase: only posts that match it inside the publication are returned.
postsAfterstringOptional date as YYYY-MM-DD.
includeBodybooleanAdd the text of each post as read by a logged-out visitor.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/substack-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'publications': ['on.substack.com'], 'maxItems': 20}

run = client.actor("v0iddo/substack-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "publications": [
    "on.substack.com"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/substack-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~substack-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"publications": ["on.substack.com"], "maxItems": 20}'

Price

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Works for any publication, including those on their own domain. Use the address the publication is read at; a name.substack.com address of a publication that moved to its own domain does not work.
  • Author names, profiles, handles and photos are not collected.
  • Reactions are the heart count shown on the post.
  • With post text switched on, each post costs one more request, so the run is slower.

FAQ

What data does the Substack Posts Scraper return?

Each result is one row in an Apify dataset. Fields include title, subtitle, date, audience, reactions, comments, wordCount, section, and more. The table above shows every field with an example value.

How do I use the Substack Posts Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/substack-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
