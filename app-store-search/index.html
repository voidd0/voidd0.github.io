Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "queries": [
    "meditation",
    "habit tracker"
  ]
}
Input fieldTypeWhat it does
queriesarrayKeywords to search for. Each query is run against each country independently.
countriesarrayISO 3166-1 alpha-2 storefront codes.
limitintegerMax results per query. iTunes Search caps at 200.
entitystringWhich Apple catalog to search.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/app-store-search.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'queries': ['meditation', 'habit tracker']}

run = client.actor("v0iddo/app-store-search").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "queries": [
    "meditation",
    "habit tracker"
  ]
};

const run = await client.actor('v0iddo/app-store-search').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~app-store-search/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["meditation", "habit tracker"]}'

FAQ

What data does the App Store Search Scraper return?

Each result is one row in an Apify dataset. Fields include snapshotAt, query, country, rank, appId, bundleId, trackName, artistName, and more. The table above shows every field with an example value.

How do I use the App Store Search Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/app-store-search with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.20 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.14 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the limit input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
