Time Zone Converter: how to get IANA Zones, DST, Offsets, Batch as JSON/CSV (API, Python, no code)

Convert a date and time between IANA time zones with exact daylight-saving handling, inspect a zone's offset and transitions, or list a country's zones. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/time-zone-converter on Apify.

Input fieldTypeWhat it does
opstringOne of: convert, info, list.
datetimestringISO 8601, e.g. 2026-03-29T01:30:00 (wall clock in from_tz / tz) or 2026-03-29T00:30:00Z / 2026-03-29T01:30:00+01:00 (exact instant).
from_tzstringconvert: source zone, an IANA name such as Europe/Berlin or a fixed offset such as +05:30.
to_tzstringconvert: target zone, an IANA name or a fixed offset.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/time-zone-converter.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'op': 'convert',
 'datetime': '2026-03-29T01:30:00',
 'from_tz': 'Europe/Berlin',
 'to_tz': 'America/New_York'}

run = client.actor("v0iddo/time-zone-converter").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "op": "convert",
  "datetime": "2026-03-29T01:30:00",
  "from_tz": "Europe/Berlin",
  "to_tz": "America/New_York"
};

const run = await client.actor('v0iddo/time-zone-converter').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~time-zone-converter/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"op": "convert", "datetime": "2026-03-29T01:30:00", "from_tz": "Europe/Berlin", "to_tz": "America/New_York"}'

FAQ

What data does the Time Zone Converter return?

Each result is one row in an Apify dataset. Fields include index, input, from_tz, output, offset_from, offset_to, dst_to, day_offset, and more. The table above shows every field with an example value.

How do I use the Time Zone Converter from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/time-zone-converter with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
