Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/fcc-public-notices.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'proceeding': ['17-108', '21-450', '23-65']}

run = client.actor("v0iddo/fcc-public-notices").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "proceeding": [
    "17-108",
    "21-450",
    "23-65"
  ]
};

const run = await client.actor('v0iddo/fcc-public-notices').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~fcc-public-notices/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"proceeding": ["17-108", "21-450", "23-65"]}'

FAQ

What data does the FCC ECFS public notices scraper return?

Each result is one row in an Apify dataset. Fields include snapshotAt, filing_id, date_received, submission_type, filer_name, proceeding, document_filename, document_url, and more. The table above shows every field with an example value.

How do I use the FCC ECFS public notices scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/fcc-public-notices with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.
