Remote Jobs Scraper: how to get remote jobs from RemoteOK, WWR and Jobicy as JSON/CSV (API, Python, no code)

Scrape remote jobs from Remote OK, We Work Remotely, Jobicy, Working Nomads and Arbeitnow in one feed: title, company, location, eligible countries, salary, job type, level, tags, posted date and description. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/remote-jobs-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "engineer",
    "developer"
  ],
  "maxItems": 20,
  "maxJobsPerBoard": 6
}
Input fieldTypeWhat it does
keywordsarrayJob titles, skills or words such as python, designer or customer support.
searchDescriptionsbooleanAlso keep jobs whose description holds a search term.
excludeKeywordsarrayDrop jobs whose title holds any of these words, such as senior or intern.
sourcesarrayThe boards to read, in this order.
maxJobsPerBoardintegerOptional. Stop reading a board after this many kept jobs and go on to the next one, so the first board does not fill the whole run.
locationsarrayOnly jobs whose location or eligible countries name one of these, such as USA, Europe, Germany or Canada.
includeWorldwidebooleanWith locations set, also keep jobs open to people anywhere in the world.
postedWithinstringOnly jobs published in that period.
salaryOnlybooleanOnly jobs whose board gives a salary (Remote OK and Jobicy give one for about a quarter and a half of their jobs).
includeDescriptionbooleanReturn each job's description as plain text.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/remote-jobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['engineer', 'developer'], 'maxItems': 20, 'maxJobsPerBoard': 6}

run = client.actor("v0iddo/remote-jobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "engineer",
    "developer"
  ],
  "maxItems": 20,
  "maxJobsPerBoard": 6
};

const run = await client.actor('v0iddo/remote-jobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~remote-jobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["engineer", "developer"], "maxItems": 20, "maxJobsPerBoard": 6}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One run reads every board you chose, about 4,000 jobs in all on a normal day: Remote OK's 100 newest plus 100 per search term, We Work Remotely's main and category feeds, Jobicy's last 7 days...
  • Rows come board by board in the order of Job boards, newest first within a board. A job with the same company and title as one already returned (the same job posted on two boards) is left out.
  • source and sourceName say which board the job comes from, and url is the job on that board. The boards ask that apps showing their jobs name them and link to the job there.
  • location is the board's own text (Anywhere in the World, USA, Europe ...); countries lists the eligible countries where We Work Remotely gives them; worldwide is true when the location says...

FAQ

What data does the Remote Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, salaryMin, salaryMax, salaryCurrency, sourceName, publishedAt, and more. The table above shows every field with an example value.

How do I use the Remote Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/remote-jobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
