WHOIS Domain Lookup: how to get Registrar, Age, Expiry, Name Servers as JSON/CSV (API, Python, no code)

WHOIS lookup for any domain: registrar, creation and expiry dates, domain age, days to expiry, name servers, status and DNSSEC, read live from the registry's RDAP service. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/whois-domain-lookup on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/whois-domain-lookup.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'query': 'github.com'}

run = client.actor("v0iddo/whois-domain-lookup").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "query": "github.com"
};

const run = await client.actor('v0iddo/whois-domain-lookup').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~whois-domain-lookup/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "github.com"}'

FAQ

What data does the WHOIS Domain Lookup return?

Each result is one row in an Apify dataset. Fields include index, query, ldhName, registrar, events, age_days, days_to_expiry, status, and more. The table above shows every field with an example value.

How do I use the WHOIS Domain Lookup from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/whois-domain-lookup with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
