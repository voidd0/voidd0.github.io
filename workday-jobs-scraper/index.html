Workday Jobs Scraper: how to get Salary, Dates, Remote as JSON/CSV (API, Python, no code)

Collect every open job from any Workday careers site (myworkdayjobs.com): title, location, country, remote or on site, employment type, real posting date, pay range where the posting states it, and the description as plain text. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/workday-jobs-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "companies": [
    "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite",
    "https://salesforce.wd12.myworkdayjobs.com/External_Career_Site"
  ],
  "includeDescription": true,
  "maxItems": 50,
  "maxJobsPerCompany": 25
}
Input fieldTypeWhat it does
companies (required)arrayOne careers site link per line, at most 200.
titleKeywordsarrayOptional. Only postings whose title contains at least one of these words or phrases are returned.
locationContainsstringOptional text such as Berlin, Remote, Canada or US.
remoteOnlybooleanReturn only postings that are marked remote or say remote in their location.
postedWithinDaysintegerOptional. Skip postings that were published longer ago than this.
includeDescriptionbooleanAdd the job description as plain text, with the exact posting date, the country, the workplace and the pay range.
maxJobsPerCompanyintegerOptional. Stop reading a company after this many matching postings and go on to the next one, so a large employer first in the list does not fill the whole run.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/workday-jobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'companies': ['https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite',
               'https://salesforce.wd12.myworkdayjobs.com/External_Career_Site'],
 'includeDescription': True,
 'maxItems': 50,
 'maxJobsPerCompany': 25}

run = client.actor("v0iddo/workday-jobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "companies": [
    "https://nvidia.wd5.myworkdayjobs.com/NVIDIAExternalCareerSite",
    "https://salesforce.wd12.myworkdayjobs.com/External_Career_Site"
  ],
  "includeDescription": true,
  "maxItems": 50,
  "maxJobsPerCompany": 25
};

const run = await client.actor('v0iddo/workday-jobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~workday-jobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \

Good to know

  • Paste the link of the company's Workday job search page, the address on myworkdayjobs.com or myworkdaysite.com. Up to 200 sites per run; the company field is the Workday tenant name (for example...
  • Workday's search pages say only Posted Today or Posted 3 Days Ago. With description text on, each posting is read once more and Posted is its exact start date; with it off, the relative day is...
  • Postings listed in several locations carry every location, joined by a semicolon, and the country of the first. Remote is true when the posting is marked remote or names a remote location.
  • Pay is read from the description where the posting states a range, as in many US postings: the first range on a line about salary or pay. Interval is year or hour when the text says so.

FAQ

What data does the Workday Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include ats, company, title, department, location, remote, workplaceType, employmentType, and more. The table above shows every field with an example value.

How do I use the Workday Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/workday-jobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.90 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.63 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
