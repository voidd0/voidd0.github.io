Input fieldTypeWhat it does
keywordsarrayJob titles or words such as księgowa, kierowca or Java developer.
locationstringOptional city or town such as Warszawa, Kraków or Gdańsk.
distanceKmintegerHow far from the city postings may be.
postedWithinstringOnly postings published in that period.
positionLevelsarrayOptional. Only these levels; empty means all.
contractTypesarrayOptional. Only these contract types; empty means all.
workSchedulesarrayOptional. Only these schedules; empty means all.
workModesarrayOptional. Only these work modes; empty means all.
salaryOnlybooleanOnly postings that show a salary.
searchUrlsarraySearch result pages copied from your browser, for example https://www.pracuj.pl/praca/kierowca;kw/gdansk;wp?rd=30 .
includeDetailsbooleanRead each posting's page for the salary per contract type, the workplace address, category, technologies, responsibilities, requirements, benefits and the description.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/pracuj-pl-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['księgowa'],
 'location': 'Warszawa',
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/pracuj-pl-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "księgowa"
  ],
  "location": "Warszawa",
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/pracuj-pl-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~pracuj-pl-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["księgowa"], "location": "Warszawa", "includeDetails": true, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per search term, with the city, distance and filters you chose. Pasted search URLs keep their own filters. Postings are unique by ID across the whole run.
  • One row is one posting. A posting offered in several towns lists them all in locations; location is the first, and the address fields are those of the first workplace.
  • salaryText is the salary as the search shows it. salaryMin, salaryMax, salaryCurrency, salaryInterval (month or hour) and salaryKind (gross, net or net plus VAT) come from the posting page with...
  • positionLevels, contractTypes, workSchedules and workModes are in English (for example junior, B2B, full time, remote); category, the posting's own text and the summary stay in Polish as published.

FAQ

What data does the Pracuj.pl Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, salaryText, positionLevels, contractTypes, workModes, postedAt, and more. The table above shows every field with an example value.

How do I use the Pracuj.pl Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/pracuj-pl-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
