HTML to PDF API: how to convert HTML into A4, Letter or Legal PDF files (Python, cURL, no code)

Turn an HTML document into a print-ready PDF with page size, margins, orientation and page-numbered header and footer. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/html-to-pdf on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/html-to-pdf.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'html': '<h1>Invoice #1042</h1><p>Total due: 120.00 USD, payable within 14 '
         'days.</p>'}

run = client.actor("v0iddo/html-to-pdf").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "html": "<h1>Invoice #1042</h1><p>Total due: 120.00 USD, payable within 14 days.</p>"
};

const run = await client.actor('v0iddo/html-to-pdf').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~html-to-pdf/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"html": "<h1>Invoice #1042</h1><p>Total due: 120.00 USD, payable within 14 days.</p>"}'

FAQ

What data does the HTML to PDF API return?

Each result is one row in an Apify dataset. Fields include index, file_url, filename, mime, bytes, credits, ms, file_key, and more. The table above shows every field with an example value.

How do I use the HTML to PDF API from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/html-to-pdf with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
