Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/sec-8k-material-events-tracker.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'tickers': ['TSLA', 'JPM']}

run = client.actor("v0iddo/sec-8k-material-events-tracker").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "tickers": [
    "TSLA",
    "JPM"
  ]
};

const run = await client.actor('v0iddo/sec-8k-material-events-tracker').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~sec-8k-material-events-tracker/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["TSLA", "JPM"]}'

FAQ

What data does the SEC 8-K Scraper return?

Each result is one row in an Apify dataset. Fields include ticker, companyCik, companyName, filingDate, reportDate, accessionNumber, items, itemSummaries, and more. The table above shows every field with an example value.

How do I use the SEC 8-K Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/sec-8k-material-events-tracker with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.
