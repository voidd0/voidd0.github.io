Google Maps Scraper: how to get Places, Phones, Hours as JSON/CSV (API, Python, no code)

Scrape Google Maps business listings by search and place: name, category, address, coordinates, rating, review count, phone, website, opening hours, place ID and Maps link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/google-maps-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "searchQueries": [
    "coffee shop"
  ],
  "location": "Berlin",
  "language": "en",
  "maxItems": 20
}
Input fieldTypeWhat it does
searchQueriesarrayWhat to look for on Google Maps, one per line, for example: coffee shop, plumber, dentist.
locationstringOptional city, area or address added to every query as 'query in location', for example Berlin or Austin, TX.
startUrlsarrayOptional Google Maps search links, for example https://www.google.com/maps/search/coffee+in+berlin.
languagestringLanguage of the Google Maps page: category names, days and hours.
maxPlacesPerSearchintegerStop each search after this many places (0 = as many as Google Maps lists, usually 100 to 200).
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/google-maps-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchQueries': ['coffee shop'],
 'location': 'Berlin',
 'language': 'en',
 'maxItems': 20}

run = client.actor("v0iddo/google-maps-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchQueries": [
    "coffee shop"
  ],
  "location": "Berlin",
  "language": "en",
  "maxItems": 20
};

const run = await client.actor('v0iddo/google-maps-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~google-maps-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchQueries": ["coffee shop"], "location": "Berlin", "language": "en", "maxItems": 20}'

Price

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Reads the public Google Maps search pages the way a visitor's browser does, with no login and no Google account. robots.txt of www.google.com allows these pages and the actor obeys it.
  • Google lists about 100 to 200 places for one search; for more, add queries or split by area ('dentist in Camden', 'dentist in Soho').
  • Phone and website are what the listing shows publicly for the business; many listings show no phone or website and have null there. No reviews or reviewer names are collected.
  • If Google shows a consent page, a CAPTCHA or an 'unusual traffic' page, the run stops and says so; the actor does not try to get around it. Run it again later.

FAQ

What data does the Google Maps Scraper return?

Each result is one row in an Apify dataset. Fields include name, category, address, city, rating, reviewsCount, phone, website, and more. The table above shows every field with an example value.

How do I use the Google Maps Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/google-maps-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
