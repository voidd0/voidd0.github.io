Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "python"
  ],
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayJob titles, skills or words such as python, data analyst, telecaller or delivery boy, one per line.
locationstringOptional city such as Bengaluru, Mumbai, Delhi, Gurugram, Hyderabad, Pune or Chennai (Bangalore, Bombay and the other old names work too), or remote for work from home...
sourcesarrayThe boards to search; all five by default.
salaryOnlybooleanOnly jobs that show a salary range.
includeDetailsbooleanInstahyre jobs get their posting date and experience range from the job's own page: one more request per Instahyre job, so slower.
maxItemsintegerThe run stops after this many result rows.
onlyNewbooleanSkip rows that an earlier run with the same input, or with the same State key, already returned, so a scheduled run gives each new row once, with isNew true and firstS...
stateKeystringOptional, with Only new results: a name for the list of rows already returned.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/india-jobs-feed.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['python'], 'maxItems': 20}

run = client.actor("v0iddo/india-jobs-feed").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "python"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/india-jobs-feed').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~india-jobs-feed/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["python"], "maxItems": 20}'

Price

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each search term runs on every board you pick, in the city you chose. The run takes one job from each board in turn, so a small Maximum results still shows every board.
  • A job listed on two boards, or twice on one, comes once: the first board that gave it keeps it. Two jobs are the same when their title, company and city match once written alike (Bengaluru and...
  • salaryMin, salaryMax, salaryCurrency and salaryPeriod are the employer's own figures: per month on Apna.co and Internshala, per year on Hirist and IIMJobs (their lakhs written out in rupees, so 20...
  • experienceMin and experienceMax are years of experience as the board states them. remote is true for work from home jobs and internship for internships; Internshala lists internships and fresher jobs.

FAQ

What data does the India Jobs Feed return?

Each result is one row in an Apify dataset. Fields include title, company, city, source, salaryMin, salaryMax, salaryCurrency, salaryPeriod, and more. The table above shows every field with an example value.

How do I use the India Jobs Feed from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/india-jobs-feed with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
