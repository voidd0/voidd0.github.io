Website content crawler: how to get clean page text as JSON/CSV (API, Python, no code)

Crawls any public website from a start URL, follows internal links up to a set depth, and extracts title, breadcrumbs, clean text body, and word count. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/website-content-crawler on Apify.

Input fieldTypeWhat it does
startUrls (required)arrayOne or more page URLs to begin crawling from.
maxDepthintegerHow many link-hops from the start URL to follow.
maxPagesPerUrlintegerHard cap on pages fetched per start URL, independent of the global maxItems limit.
includeUrlPatternstringOptional regex. Only URLs matching this pattern are crawled.
excludeUrlPatternstringOptional regex. URLs matching this pattern are skipped.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/website-content-crawler.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'startUrls': ['https://docs.python.org/3/library/'],
 'maxDepth': 1,
 'maxPagesPerUrl': 15,
 'maxItems': 20}

run = client.actor("v0iddo/website-content-crawler").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "startUrls": [
    "https://docs.python.org/3/library/"
  ],
  "maxDepth": 1,
  "maxPagesPerUrl": 15,
  "maxItems": 20
};

const run = await client.actor('v0iddo/website-content-crawler').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~website-content-crawler/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://docs.python.org/3/library/"], "maxDepth": 1, "maxPagesPerUrl": 15, "maxItems": 20}'

Price

$2.55 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.78 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • The crawler stays within the same origin and path prefix as each start URL. Use includeUrlPattern or excludeUrlPattern to narrow scope on large sites; combine with maxPagesPerUrl to control cost.
  • Set maxDepth=0 to extract only the start page. maxDepth=1 adds all pages linked from the start page. Depths above 3 can produce thousands of pages on large sites.
  • Pages behind login, paywalls, or bot walls are not accessible.
  • Not affiliated with any documentation platform or website.

FAQ

What data does the Website content crawler return?

Each result is one row in an Apify dataset. Fields include url, title, h1, breadcrumbs, description, textContent, wordCount, depth. The table above shows every field with an example value.

How do I use the Website content crawler from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/website-content-crawler with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.55 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.78 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
