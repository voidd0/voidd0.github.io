Yahoo Finance Scraper: how to get Stock Quotes and Key Statistics as JSON/CSV (API, Python, no code)

This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/yahoo-finance-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/yahoo-finance-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'tickers': ['AAPL',
             'MSFT',
             'NVDA',
             'AMZN',
             'GOOGL',
             'META',
             'TSLA',
             'SPY',
             'QQQ',
             '^GSPC',
             'BTC-USD',
             'EURUSD=X'],
 'maxItems': 20}

run = client.actor("v0iddo/yahoo-finance-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "tickers": [
    "AAPL",
    "MSFT",
    "NVDA",
    "AMZN",
    "GOOGL",
    "META",
    "TSLA",
    "SPY",
    "QQQ",
    "^GSPC",
    "BTC-USD",
    "EURUSD=X"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/yahoo-finance-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~yahoo-finance-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["AAPL", "MSFT", "NVDA", "AMZN", "GOOGL", "META", "TSLA", "SPY", "QQQ", "^GSPC", "BTC-USD", "EURUSD=X"], "maxItems": 20}'

Good to know

  • One row per ticker, read from the public quote page finance.yahoo.com/quote/TICKER/. That page already carries the quote and the key statistics, so the run makes one request per ticker.
  • Prices are Yahoo's public quotes, delayed by up to 15 minutes on some exchanges (crypto and currencies are close to live). When a market is closed, price is the last regular session price and...
  • changePercent and dividendYield are percentages: 0.43 means 0.43 percent. Dates are ISO 8601: exDividendDate and earningsDate as YYYY-MM-DD, regularMarketTime and scrapedAt in UTC.
  • A field that does not exist for the kind of instrument comes back as null, for example no dividend for an index, no sector for a crypto and no market cap for an ETF. For funds, dividendYield is...

FAQ

What data does the Yahoo Finance Scraper return?

Each result is one row in an Apify dataset. Fields include symbol, name, quoteType, price, currency, changePercent, volume, marketCap, and more. The table above shows every field with an example value.

How do I use the Yahoo Finance Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/yahoo-finance-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
