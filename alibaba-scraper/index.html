Alibaba Scraper: how to get Prices, MOQ, Suppliers as JSON/CSV (API, Python, no code)

Scrape Alibaba.com product offers by keyword: title, price range and quantity price tiers, minimum order, units sold, ratings, certifications, and the supplier's name, country, years, Gold and verified badges, Trade Assurance and response rate. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/alibaba-scraper on Apify.

Input fieldTypeWhat it does
searchTermsarrayProducts as a buyer would type them, one per line, for example led strip lights.
searchUrlsarrayOptional alibaba.com keyword pages (https://www.alibaba.com/wholesale/....html).
maxPagesintegerHow many result pages (about 47 offers each) to read per keyword.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/alibaba-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchTerms': ['led strip lights'], 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/alibaba-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchTerms": [
    "led strip lights"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/alibaba-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~alibaba-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["led strip lights"], "maxPages": 1, "maxItems": 20}'

Price

$0.75 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.53 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Reads Alibaba's public keyword pages (alibaba.com/wholesale/...). Its search box pages are closed to automated access in robots.txt, so filters such as price range or supplier type are not offered.
  • Most product keywords have a page. When one has none, the run tries the plural once and logs the keyword if that has none either.
  • Prices are as shown to a visitor of the English site, usually in US dollars; quantityPrices lists the price per quantity tier when the offer has tiers.
  • Supplier contact details are not collected.

FAQ

What data does the Alibaba Scraper return?

Each result is one row in an Apify dataset. Fields include productId, title, priceMin, priceMax, minOrder, minOrderUnit, sold, supplierName, and more. The table above shows every field with an example value.

How do I use the Alibaba Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/alibaba-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.75 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.53 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
