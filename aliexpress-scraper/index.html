AliExpress Scraper: how to get Prices, Sold Counts as JSON/CSV (API, Python, no code)

Scrape AliExpress search results into product rows: product ID, title, sale price, original price, discount, star rating, units sold, Choice and shipping flags, delivery estimate, image and link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/aliexpress-scraper on Apify.

includeAdsbooleanKeep promoted products (they are marked with ad = true).

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/aliexpress-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchTerms': ['wireless earbuds'], 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/aliexpress-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchTerms": [
    "wireless earbuds"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/aliexpress-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~aliexpress-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["wireless earbuds"], "maxPages": 1, "maxItems": 20}'

Price

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Prices are in US dollars as shown to a visitor shipping to the United States.
  • Units sold is the figure AliExpress shows, such as 1,000+ sold; soldText keeps the original wording.
  • AliExpress shows at most 60 result pages for one search; use narrower search terms to collect more products.

FAQ

What data does the AliExpress Scraper return?

Each result is one row in an Apify dataset. Fields include productId, title, price, originalPrice, rating, sold, choice, url, and more. The table above shows every field with an example value.

How do I use the AliExpress Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/aliexpress-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
