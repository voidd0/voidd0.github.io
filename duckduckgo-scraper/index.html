Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/duckduckgo-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'queries': ['web scraping tools', 'python tutorial'],
 'region': 'us-en',
 'maxPages': 1,
 'safeSearch': 'moderate',
 'maxItems': 20}

run = client.actor("v0iddo/duckduckgo-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "queries": [
    "web scraping tools",
    "python tutorial"
  ],
  "region": "us-en",
  "maxPages": 1,
  "safeSearch": "moderate",
  "maxItems": 20
};

const run = await client.actor('v0iddo/duckduckgo-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~duckduckgo-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["web scraping tools", "python tutorial"], "region": "us-en", "maxPages": 1, "safeSearch": "moderate", "maxItems": 20}'

Price

$0.51 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.36 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Returns organic web search results from DuckDuckGo. Each page yields about 10 results; increase pages per query to collect more results for a single query.
  • Use a region code such as us-en, uk-en, or de-de to get results localized to a country. A full list of region codes is available at duckduckgo.com/params.
  • DuckDuckGo does not expose a paginated web search API; results are read from the static HTML endpoint that DuckDuckGo maintains for non-JavaScript browsers.
  • Not affiliated with DuckDuckGo.

FAQ

What data does the DuckDuckGo Search Scraper return?

Each result is one row in an Apify dataset. Fields include query, position, title, url, displayUrl, snippet, page. The table above shows every field with an example value.

How do I use the DuckDuckGo Search Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/duckduckgo-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.51 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.36 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
