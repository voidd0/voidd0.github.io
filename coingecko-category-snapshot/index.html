CoinGecko Scraper: how to get Crypto Market Data by Category as JSON/CSV (API, Python, no code)

For each CoinGecko category ID (layer-1, defi, meme-token, etc.), pull its coins by market cap: 250 per category by default, more if you raise the cap. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/coingecko-category-snapshot on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "categories": [
    "layer-1",
    "meme-token"
  ],
  "maxCoinsPerCategory": 20
}
Input fieldTypeWhat it does
categories (required)arrayCoinGecko category identifiers (lower-case, kebab-cased).
vsCurrencystringISO code for the price quote.
maxCoinsPerCategoryintegerHard cap per category. CoinGecko pages 250 at a time on its public API.
include24hChangebooleanAdds priceChangePct24h field.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/coingecko-category-snapshot.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categories': ['layer-1', 'meme-token'], 'maxCoinsPerCategory': 20}

run = client.actor("v0iddo/coingecko-category-snapshot").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categories": [
    "layer-1",
    "meme-token"
  ],
  "maxCoinsPerCategory": 20
};

const run = await client.actor('v0iddo/coingecko-category-snapshot').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~coingecko-category-snapshot/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categories": ["layer-1", "meme-token"], "maxCoinsPerCategory": 20}'

FAQ

What data does the CoinGecko Scraper return?

Each result is one row in an Apify dataset. Fields include category, vsCurrency, snapshotAt, id, symbol, name, image, currentPrice, and more. The table above shows every field with an example value.

How do I use the CoinGecko Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/coingecko-category-snapshot with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.
