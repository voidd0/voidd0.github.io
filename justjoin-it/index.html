This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/justjoin-it on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "categories": [
    "python"
  ],
  "salaryOnly": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
categoriesarraySite categories such as python, javascript, java, devops, data, testing or mobile, one per line; the names the site shows (.NET, UX/UI, C++) work too.
keywordsarrayOptional words such as django, react, kotlin or sap, searched the way the site's search box does.
locationstringOptional city such as Warszawa, Krakow, Wroclaw, Gdansk or Poznan (Warsaw and Polish letters work too), or remote for fully remote offers.
experienceLevelsarrayOptional. Only offers at these levels; empty means all.
workModesarrayOptional. Only remote, hybrid, office or mobile offers; empty means all.
contractTypesarrayOptional. Only offers with one of these contracts (B2B, employment contract UoP, mandate contract UZ, contract for specific work UoD); empty means all.
salaryOnlybooleanOnly offers that show a salary range, as the site's With salary filter.
postedWithinstringOnly offers published in that period.
sortBystringThe order of the site's listing: its default, newest first or highest salary first.
offersPerSearchintegerOptional cap for each search (category and keyword), so one search does not use the whole run.
searchUrlsarrayJustJoin.it listing pages copied from your browser, for example https://justjoin.it/job-offers/krakow/java?experience-levels=senior .
maxItemsintegerThe run stops after this many result rows.
onlyNewbooleanSkip rows that an earlier run with the same input already returned, so a scheduled run gives each new row once.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/justjoin-it.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categories': ['python'], 'salaryOnly': True, 'maxItems': 20}

run = client.actor("v0iddo/justjoin-it").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categories": [
    "python"
  ],
  "salaryOnly": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/justjoin-it').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~justjoin-it/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categories": ["python"], "salaryOnly": true, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per category and keyword, in the city you choose and with the filters you set. Pasted listing URLs keep their own filters. Each offer comes once per run, however many searches list it.
  • salaryFrom, salaryTo, currency, salaryInterval (month, day, hour or year) and salaryType (gross or net) are the employer's own figures for contractType, the first contract with a salary the offer...
  • contractType and contractTypes are in English: B2B, employment contract (umowa o prace, UoP), mandate contract (umowa zlecenie), contract for specific work (umowa o dzielo) and internship. An...
  • With a salary only keeps the offers that show a salary range, as the site's own filter does. Without it, offers whose salary is not disclosed come with empty salary fields.

FAQ

What data does the JustJoin.it Scraper return?

Each result is one row in an Apify dataset. Fields include title, companyName, city, workMode, seniority, skills, salaryFrom, salaryTo, and more. The table above shows every field with an example value.

How do I use the JustJoin.it Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/justjoin-it with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
