Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "sinceDays": 30,
  "includeFullText": false,
  "userAgent": "voiddo studio us-executive-orders ops@voiddo.com"
}
Input fieldTypeWhat it does
sinceDaysintegerHow many days back from today.
sincestringFilter by publication_date >= this.
untilstringInclusive. Defaults to today.
subtypesarrayFilter by document subtype.
includeFullTextbooleanIf true, additionally fetch the document's raw text from federalregister.gov.
userAgentstringOverride only if Federal Register rejects the default.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/us-executive-orders-tracker.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'sinceDays': 30,
 'includeFullText': False,
 'userAgent': 'voiddo studio us-executive-orders ops@voiddo.com'}

run = client.actor("v0iddo/us-executive-orders-tracker").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "sinceDays": 30,
  "includeFullText": false,
  "userAgent": "voiddo studio us-executive-orders ops@voiddo.com"
};

const run = await client.actor('v0iddo/us-executive-orders-tracker').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~us-executive-orders-tracker/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"sinceDays": 30, "includeFullText": false, "userAgent": "voiddo studio us-executive-orders ops@voiddo.com"}'

FAQ

What data does the US executive orders scraper return?

Each result is one row in an Apify dataset. Fields include documentNumber, type, subtype, title, executiveOrderNumber, presidentialDocumentNumber, signingDate, publicationDate, and more. The table above shows every field with an example value.

How do I use the US executive orders scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/us-executive-orders-tracker with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.
