This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/tiktok-shop-product-scraper on Apify.

Price

$2.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.89 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Reads public TikTok Shop product pages in the United States only (shop.tiktok.com/us/pdp). No login and no account cookies are used. If TikTok shows a verification page or its anti-crawler notice...
  • Not affiliated with TikTok. The data is what a visitor who is not logged in sees on the product page.
  • One row per product, at most 500 products per run. Each product is one page request (two when the link has no product name in it), a few seconds apart.
  • Units sold is the count TikTok prints on the page (items sold since the product was listed). Review count and the star breakdown are numbers only: no review text, reviewer names or creator videos...

FAQ

What data does the TikTok Shop Scraper return?

Each result is one row in an Apify dataset. Fields include productId, title, price, originalPrice, currency, soldCount, rating, reviewCount, and more. The table above shows every field with an example value.

How do I use the TikTok Shop Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/tiktok-shop-product-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.89 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
