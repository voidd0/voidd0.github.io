Talabat Scraper: how to get the data as JSON/CSV (API, Python, no code)

Scrape Talabat restaurant listings by country: restaurant ID, name, cuisines, category, logo and direct URL. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/talabat-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "listingUrls": [
    "https://www.talabat.com/uae/restaurants"
  ],
  "maxPages": 1,
  "maxItems": 20
}
Input fieldTypeWhat it does
listingUrls (required)arrayTalabat country or area restaurant listing pages, for example https://www.talabat.com/uae/restaurants or https://www.talabat.com/kuwait/restaurants.
maxPagesintegerHow many listing pages to read per URL (up to 30 restaurants each).
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/talabat-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'listingUrls': ['https://www.talabat.com/uae/restaurants'],
 'maxPages': 1,
 'maxItems': 20}

run = client.actor("v0iddo/talabat-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "listingUrls": [
    "https://www.talabat.com/uae/restaurants"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/talabat-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~talabat-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"listingUrls": ["https://www.talabat.com/uae/restaurants"], "maxPages": 1, "maxItems": 20}'

Price

$0.71 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.50 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers Talabat countries: UAE, Kuwait, Bahrain, Oman, Qatar, Saudi Arabia, Jordan, Iraq and Egypt. Use a country listing URL such as https://www.talabat.com/uae/restaurants.
  • Each listing page returns up to 30 restaurants. Use maxPages to control how many pages are read per listing URL.
  • Rating, delivery fee and minimum order are not exposed on listing pages and are not included in the output.
  • Not affiliated with Talabat or Delivery Hero.

FAQ

What data does the Talabat Scraper return?

Each result is one row in an Apify dataset. Fields include restaurantId, name, slug, country, cuisines, logoUrl, url. The table above shows every field with an example value.

How do I use the Talabat Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/talabat-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.71 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.50 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
