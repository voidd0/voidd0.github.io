Canada Job Bank Scraper: how to get Jobs, Salaries and NOC Codes as JSON/CSV (API, Python, no code)

Scrape Canada jobbank listings from jobbank.gc.ca by keyword and location: job title, employer, city and province, salary range, posting date, remote status, direct apply flag, and posting source. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/jobbank on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/jobbank.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['software developer', 'nurse'],
 'location': '',
 'maxPages': 1,
 'maxItems': 20}

run = client.actor("v0iddo/jobbank").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "software developer",
    "nurse"
  ],
  "location": "",
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/jobbank').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~jobbank/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["software developer", "nurse"], "location": "", "maxPages": 1, "maxItems": 20}'

Price

$0.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.49 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers public search results on jobbank.gc.ca (Government of Canada). Each keyword runs as a separate search; use specific job titles or add a location to narrow results.
  • Detail pages (/jobsearch/jobposting/...) are closed to automated access per the site robots.txt and are not fetched. All data comes from the search result cards on the listing pages.
  • Each search page holds about 10 results. The site caps results at roughly 25 pages per keyword (around 250 jobs). Set maxPages to 25 to collect the full set for a given keyword.
  • Not affiliated with the Government of Canada or jobbank.gc.ca.

FAQ

What data does the Canada Job Bank Scraper return?

Each result is one row in an Apify dataset. Fields include jobId, title, employer, location, salaryMin, salaryMax, salaryUnit, postingDate, and more. The table above shows every field with an example value.

How do I use the Canada Job Bank Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/jobbank with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.49 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
