Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "pageUrls": [
    "https://en.wikipedia.org/wiki/Hummingbird"
  ],
  "fileTypes": [
    "image"
  ],
  "maxFilesPerPage": 20,
  "maxItems": 20
}
Input fieldTypeWhat it does
fileUrlsarrayDirect links to files of any type (images, video, audio, PDF, documents, archives).
pageUrlsarrayWeb pages to download files from: the images it shows (the largest size it offers), its video and audio, and the files it links to, filtered by File types.
fileTypesarrayWhich files to take from Pages.
sameSiteOnlybooleanTake only files on the host of the page or its subdomains, leaving out files on other hosts (many sites keep their images on a separate CDN host, so this can drop them).
maxFilesPerPageintegerCaps the files taken from one page, in the order they appear on it.
minImageKBintegerImages found on pages that are smaller than this are left out (icons, spacers, tracking pixels) and not charged; 0 keeps every image.
maxFileMBintegerLarger files come back as a row with the reason, at no charge.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/bulk-file-downloader.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'pageUrls': ['https://en.wikipedia.org/wiki/Hummingbird'],
 'fileTypes': ['image'],
 'maxFilesPerPage': 20,
 'maxItems': 20}

run = client.actor("v0iddo/bulk-file-downloader").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "pageUrls": [
    "https://en.wikipedia.org/wiki/Hummingbird"
  ],
  "fileTypes": [
    "image"
  ],
  "maxFilesPerPage": 20,
  "maxItems": 20
};

const run = await client.actor('v0iddo/bulk-file-downloader').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~bulk-file-downloader/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"pageUrls": ["https://en.wikipedia.org/wiki/Hummingbird"], "fileTypes": ["image"], "maxFilesPerPage": 20, "maxItems": 20}'

Price

$2.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.40 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One row per file: the stored copy (fileUrl), the link it came from, the page it was found on and where on the page (img, srcset, link, video, og:image ...), its name, type, content type, size...
  • The files are records in the run's key-value store; fileUrl opens them directly and works in the dataset table, in spreadsheets and in your own code. They are kept as long as your Apify plan keeps...
  • Images on pages come in the largest size the page offers in srcset, and lazy loading attributes (data-src and the like) are read, so the real image is taken instead of a placeholder.
  • The same file under two links is stored once: the second row has duplicateOf and costs nothing. A link that appears on several pages is downloaded once.

FAQ

What data does the Bulk file and image downloader return?

Each result is one row in an Apify dataset. Fields include fileUrl, fileName, fileType, fileBytes, imageWidth, imageHeight, altText, url, and more. The table above shows every field with an example value.

How do I use the Bulk file and image downloader from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/bulk-file-downloader with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.40 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
