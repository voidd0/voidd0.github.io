Vinted Product Scraper: how to get Search Listings, Prices, Brands, Sizes as JSON/CSV (API, Python, no code)

Collect public Vinted listings by search word or catalog link: title, brand, size, condition, price with currency, total with the buyer fee, favourites, photo and link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/vinted-scraper on Apify.

domainstringWhich Vinted site the search terms are run on.

priceTostringOptional highest item price as a number such as 40 or 99.99, in the currency of the country site.

maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/vinted-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchTerms': ['nike'], 'maxItems': 20}

run = client.actor("v0iddo/vinted-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchTerms": [
    "nike"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/vinted-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~vinted-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["nike"], "maxItems": 20}'

Price

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • A page holds 96 items and Vinted shows about 10 pages (960 items) for one search. Use price ranges, other sort orders or more search terms to reach further.
  • Total with buyer fee is the price plus Vinted's buyer protection fee, as shown on the listing card. Shipping is not included.
  • Sellers are never collected: no names, ids, profiles or ratings. Only the listing itself is read.
  • Size is empty for items without a size (bags, books, home goods). vinted.co.uk is the best-tested site; the other country sites use the same page layout.

FAQ

What data does the Vinted Product Scraper return?

Each result is one row in an Apify dataset. Fields include title, brand, size, condition, price, currency, totalPrice, favourites, and more. The table above shows every field with an example value.

How do I use the Vinted Product Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/vinted-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
