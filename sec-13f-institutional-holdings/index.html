Input fieldTypeWhat it does
filerCiks (required)arrayList of SEC EDGAR Central Index Keys (CIKs) for the institutional managers you want to track.
lookbackQuartersintegerHow many of the most recent 13F-HR filings to pull per filer.
includeAmendmentsbooleanIf true, also pull 13F-HR/A (amendment) filings, which restate or correct prior 13F-HR.
userAgentstringSEC requires a polite User-Agent identifying the requesting party.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/sec-13f-institutional-holdings.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'filerCiks': ['1067983']}

run = client.actor("v0iddo/sec-13f-institutional-holdings").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "filerCiks": [
    "1067983"
  ]
};

const run = await client.actor('v0iddo/sec-13f-institutional-holdings').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~sec-13f-institutional-holdings/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"filerCiks": ["1067983"]}'

FAQ

What data does the SEC 13F Scraper return?

Each result is one row in an Apify dataset. Fields include filerCik, filerName, filingManager, form, accessionNumber, filingDate, periodOfReport, isAmendment, and more. The table above shows every field with an example value.

How do I use the SEC 13F Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/sec-13f-institutional-holdings with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
