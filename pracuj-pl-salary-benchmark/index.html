Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "jobTitles": [
    "księgowa"
  ],
  "location": "Warszawa",
  "listingsPerBenchmark": 100,
  "detailPages": 10,
  "maxItems": 20
}
Input fieldTypeWhat it does
jobTitlesarrayJob titles as postings name them, one per line, for example księgowa, kierowca or Java developer.
locationstringOptional city or town such as Warszawa, Kraków or Gdańsk, for a benchmark of that place; empty means all of Poland.
distanceKmintegerHow far from the city postings may be.
contractTypesarrayOptional. Only postings that offer one of these contract types; empty means all.
positionLevelsarrayOptional. Only postings at one of these levels; empty means all.
listingsPerBenchmarkintegerPostings counted for each benchmark, in pracuj.pl's order (50 a page).
detailPagesintegerPosting pages read for each benchmark: first those whose search card does not say gross or net, then spread over the other postings.
titleMustMatchbooleanCount only postings whose title holds every word of the job title (case and Polish letters ignored, and a final vowel: księgowa counts Księgowy).
searchUrlsarraypracuj.pl search result pages copied from your browser, one benchmark each, for example https://www.pracuj.pl/praca/księgowa;kw/warszawa;wp?rd=30 .
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/pracuj-pl-salary-benchmark.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'jobTitles': ['księgowa'],
 'location': 'Warszawa',
 'listingsPerBenchmark': 100,
 'detailPages': 10,
 'maxItems': 20}

run = client.actor("v0iddo/pracuj-pl-salary-benchmark").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "jobTitles": [
    "księgowa"
  ],

  "maxItems": 20

const run = await client.actor('v0iddo/pracuj-pl-salary-benchmark').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

FAQ

What data does the Pracuj.pl Salary Benchmark by Job Title and City return?

Each result is one row in an Apify dataset. Fields include jobTitle, location, listingsOnSite, salariesUsed, salaryMin, salaryMedian, salaryMax, salarySharePercent, and more. The table above shows every field with an example value.

How do I use the Pracuj.pl Salary Benchmark by Job Title and City from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/pracuj-pl-salary-benchmark with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$490.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $343.00 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
