Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/sec-form4-insider-trades.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'tickers': ['AAPL', 'META']}

run = client.actor("v0iddo/sec-form4-insider-trades").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "tickers": [
    "AAPL",
    "META"
  ]
};

const run = await client.actor('v0iddo/sec-form4-insider-trades').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~sec-form4-insider-trades/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"tickers": ["AAPL", "META"]}'

FAQ

What data does the Insider Trades Scraper return?

Each result is one row in an Apify dataset. Fields include ticker, companyCik, companyName, insiderName, insiderCik, insiderRoles, officerTitle, accessionNumber, and more. The table above shows every field with an example value.

How do I use the Insider Trades Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/sec-form4-insider-trades with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.
