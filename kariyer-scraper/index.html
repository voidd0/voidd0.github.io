Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/kariyer-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'locations': ['istanbul'], 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/kariyer-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "locations": [
    "istanbul"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/kariyer-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~kariyer-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"locations": ["istanbul"], "maxPages": 1, "maxItems": 20}'

Price

$0.84 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.59 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Reads the public listing pages of kariyer.net only: 50 jobs a page and at most 100 pages a search, as the site shows them. Posting pages and candidate pages are never read; company names are the...
  • A place or listing link the site has no page for is skipped and named in the run log, never widened to all of Turkey. Jobs seen on an earlier page or search are not repeated.
  • Listed is the age the site shows (updated or posted that long ago, or the last day to apply); work model and employment type are given in English.
  • Not affiliated with Kariyer.net.

FAQ

What data does the Kariyer Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, workModel, employmentType, sector, age, dateStatus, and more. The table above shows every field with an example value.

How do I use the Kariyer Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/kariyer-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.84 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.59 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
