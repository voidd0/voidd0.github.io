Freelancer.com Jobs and Projects Scraper: how to get the data as JSON/CSV (API, Python, no code)

Scrape Freelancer.com job listings by skill: project title, description, budget range, bid count, required skills, payment verification status, and project URL. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/freelancer-jobs-projects-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/freelancer-jobs-projects-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'skills': ['python'], 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/freelancer-jobs-projects-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "skills": [
    "python"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/freelancer-jobs-projects-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~freelancer-jobs-projects-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"skills": ["python"], "maxPages": 1, "maxItems": 20}'

Price

$0.25 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.17 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each listing page shows approximately 50 projects. Pagination is capped at 20 pages per skill to prevent runaway fetches.
  • Skill slugs must match the Freelancer.com URL format exactly, e.g. web-scraping not Web Scraping. Find slugs in URLs such as freelancer.com/jobs/web-scraping/.
  • Budget figures are as displayed on the listing page; hourly projects show a per-hour range.
  • Not affiliated with Freelancer.com or Freelancer International Pty Ltd.

FAQ

What data does the Freelancer.com Jobs and Projects Scraper return?

Each result is one row in an Apify dataset. Fields include title, description, budgetMin, budgetMax, currency, bidCount, skills, paymentVerified, and more. The table above shows every field with an example value.

How do I use the Freelancer.com Jobs and Projects Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/freelancer-jobs-projects-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.25 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.17 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
