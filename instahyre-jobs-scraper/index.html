Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "keywords": [
    "python"
  ],
  "locations": [
    "Bangalore"
  ],
  "includeDetails": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
keywordsarrayWords such as python, react, data engineer or sales manager.
locationsarrayOptional cities, states or regions as Instahyre names them, such as Bangalore, Mumbai, Delhi, Gurgaon, Pune, Hyderabad, South India or Work From Home.
jobFunctionsarrayOptional Instahyre job functions, such as Backend Development, Data Science / Machine Learning, DevOps / Cloud, Product Management or Sales / Business Development.
companiesarrayOptional employer names as Instahyre shows them, for example Amazon or Accenture.
experienceYearsintegerOptional. Postings open to a candidate with this many years.
experienceLevelstringOptional. Instahyre's own level of the posting.
jobTypestringFull time jobs, internships, or both.
companySizestringOptional. Instahyre's size group of the employer.
includeDetailsbooleanOpen each posting's page for the description, posting date, experience range, employment type, region and the employer's website.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/instahyre-jobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['python'],
 'locations': ['Bangalore'],
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/instahyre-jobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "python"
  ],
  "locations": [
    "Bangalore"
  ],
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/instahyre-jobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~instahyre-jobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["python"], "locations": ["Bangalore"], "includeDetails": true, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per skill or title; postings are unique by ID across the whole run. Instahyre ranks a search by how well postings match, so the first rows fit best and a long run reaches looser...
  • A search shows at most 10,000 postings. For a broader list, split it by location, job function or company.
  • experienceMin and experienceMax are the years the posting asks for (from its page); companyEmployees is Instahyre's size band of the employer, such as 50-200.
  • Locations, job functions and companies are checked against Instahyre's own lists; the run names the ones it does not know in the log and goes on with the others.

FAQ

What data does the Instahyre Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, experienceMin, experienceMax, skills, companyEmployees, postedDate, and more. The table above shows every field with an example value.

How do I use the Instahyre Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/instahyre-jobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
