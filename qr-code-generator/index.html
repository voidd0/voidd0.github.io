QR code generator API: how to create PNG and SVG QR codes (Python, cURL, no code)

Turn text or a URL into a crisp QR code as PNG or SVG, with size and error-correction control. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/qr-code-generator on Apify.

Input fieldTypeWhat it does
text (required)stringText or URL to encode
formatstringFile format of the result.
sizeintegerEdge length in px (png)
marginintegerQuiet zone in modules
error_correctionstringHow much damage the code survives: L (7 percent), M (15), Q (25) or H (30).
fgstringColor of the dark modules as a hex value such as #000000.
bgstringBackground color as a hex value such as #ffffff.
itemsarrayOptional. A list of input objects with the same fields as above; every object is processed in its own right and the top-level fields act as shared defaults.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/qr-code-generator.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'text': 'https://utils.voiddo.com', 'format': 'png', 'size': 256}

run = client.actor("v0iddo/qr-code-generator").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "text": "https://utils.voiddo.com",
  "format": "png",
  "size": 256
};

const run = await client.actor('v0iddo/qr-code-generator').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~qr-code-generator/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text": "https://utils.voiddo.com", "format": "png", "size": 256}'

FAQ

What data does the QR code generator API return?

Each result is one row in an Apify dataset. Fields include index, file_url, filename, mime, bytes, credits, ms, file_key, and more. The table above shows every field with an example value.

How do I use the QR code generator API from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/qr-code-generator with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.70 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.19 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
