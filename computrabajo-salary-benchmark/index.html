Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "jobTitles": [
    "contador"
  ],
  "countries": [
    "mx"
  ],
  "location": "Monterrey",
  "listingsPerBenchmark": 100,
  "detailPages": 10,
  "maxItems": 20
}
Input fieldTypeWhat it does
jobTitlesarrayJob titles as postings name them, in Spanish, one per line, for example contador, vendedor or desarrollador python.
countriesarrayComputrabajo sites to read; each job title gets one benchmark in each of them.
locationstringOptional city, state or region such as Monterrey, Bogotá, Lima or Nuevo León, for a benchmark of that place.
listingsPerBenchmarkintegerPostings read for each benchmark, the newest first (20 a page).
detailPagesintegerPosting pages read for each benchmark, spread over the postings read, for contract types, schedules, experience asked, education and skills.
titleMustMatchbooleanCount only postings whose title holds every word of the job title (accents, case and the a or o ending ignored: enfermera counts Enfermero/a).
searchUrlsarrayComputrabajo search result pages copied from your browser, one benchmark each, for example https://mx.computrabajo.com/trabajo-de-contador-en-monterrey .
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/computrabajo-salary-benchmark.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'jobTitles': ['contador'],
 'countries': ['mx'],
 'location': 'Monterrey',
 'listingsPerBenchmark': 100,
 'detailPages': 10,
 'maxItems': 20}

run = client.actor("v0iddo/computrabajo-salary-benchmark").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "jobTitles": [
    "contador"
  ],
  "countries": [
    "mx"
  ],
  "location": "Monterrey",
  "listingsPerBenchmark": 100,
  "detailPages": 10,
  "maxItems": 20
};

const run = await client.actor('v0iddo/computrabajo-salary-benchmark').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~computrabajo-salary-benchmark/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"jobTitles": ["contador"], "countries": ["mx"], "location": "Monterrey", "listingsPerBenchmark": 100, "detailPages": 10, "maxItems": 20}'

Good to know

  • Reads Computrabajo's public search pages and a sample of posting pages, the same pages as our Computrabajo Scraper. Its robots.txt is obeyed: the site's own filter parameters are not used. Contact...
  • Salaries are monthly, in the currency most of the search's postings use. A range counts as its midpoint; yearly pay is divided by 12, pay every two weeks doubled and weekly pay multiplied by 52 /...
  • salarySharePercent is the share of the postings counted that show a salary at all; many employers write "A convenir" (to be agreed).
  • By default only postings whose title holds the words of the job title are counted (listingsCounted; titleMatchPercent is their share of the postings read): Computrabajo's search lists the closest...

FAQ

What data does the Computrabajo Salary Benchmark by Job Title and Country return?

Each result is one row in an Apify dataset. Fields include jobTitle, country, location, listingsOnSite, salariesUsed, salaryP25, salaryMedian, salaryP75, and more. The table above shows every field with an example value.

How do I use the Computrabajo Salary Benchmark by Job Title and Country from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/computrabajo-salary-benchmark with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$490.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $343.00 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
