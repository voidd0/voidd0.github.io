Video frame extractor: how to get frames and thumbnails from a video (API, Python, no code)

Extract still frames from video files as JPEG, PNG or WebP images with timecodes: one every N seconds, a number evenly spaced, exact times, one per scene or every keyframe, plus a contact sheet. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/video-frame-extractor on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "videoUrls": [
    "https://upload.wikimedia.org/wikipedia/commons/8/86/Modern_Times_trailer_%281936%29.webm"
  ],
  "mode": "count",
  "frameCount": 20,
  "maxItems": 20
}
Input fieldTypeWhat it does
videoUrls (required)arrayDirect links to video files: MP4, MOV, M4V, WEBM, MKV, AVI, FLV, MPEG TS, OGV, WMV, MXF or animated GIF.
modestringEvery N seconds (Seconds between frames), a number of frames spread evenly over the video (Number of frames), the times you list (Times), the first frame of each scene...
intervalSecondsintegerFor One frame every N seconds: the first frame is at Start at second.
frameCountintegerFor evenly spaced frames: each frame sits in the middle of its equal part of the video, so the first and last are not the black start and end.
timestampsarrayFor Frames at exact times: seconds or hours:minutes:seconds, such as 90, 1:30 or 00:01:30.5.
sceneSensitivitystringFor One frame per scene: how much the picture must change to count as a new scene.
startSecondsintegerSkip the part of each video before this second.
endSecondsintegerStop at this second of each video; 0 reads to the end.
maxFramesPerVideointegerCaps the frames of one video in every mode.
maxWidthintegerWider frames are scaled down to this width, keeping their shape; 0 keeps the size of the video.
imageFormatstringFile type of the frame images.
imageQualityintegerJPEG and WebP quality from 1 to 100; PNG is always lossless.
contactSheetbooleanAdd one image per video that shows its frames side by side with their times (up to 100 frames).
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/video-frame-extractor.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'videoUrls': ['https://upload.wikimedia.org/wikipedia/commons/8/86/Modern_Times_trailer_%281936%29.webm'],
 'mode': 'count',
 'frameCount': 20,
 'maxItems': 20}

run = client.actor("v0iddo/video-frame-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "videoUrls": [
    "https://upload.wikimedia.org/wikipedia/commons/8/86/Modern_Times_trailer_%281936%29.webm"
  ],
  "mode": "count",
  "frameCount": 20,
  "maxItems": 20
};

const run = await client.actor('v0iddo/video-frame-extractor').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~video-frame-extractor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"videoUrls": ["https://upload.wikimedia.org/wikipedia/commons/8/86/Modern_Times_trailer_%281936%29.webm"], "mode": "count", "frameCount": 20, "maxItems": 20}'

FAQ

What data does the Video frame extractor return?

Each result is one row in an Apify dataset. Fields include imageUrl, timecode, frameNumber, kind, videoFile, imageWidth, imageHeight, videoDurationSeconds, and more. The table above shows every field with an example value.

How do I use the Video frame extractor from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/video-frame-extractor with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.05 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
