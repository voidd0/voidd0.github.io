Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/sitemap-url-extractor.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'domains': ['stripe.com', 'shopify.com', 'vercel.com'], 'maxUrlsPerDomain': 20}

run = client.actor("v0iddo/sitemap-url-extractor").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "domains": [
    "stripe.com",
    "shopify.com",
    "vercel.com"
  ],
  "maxUrlsPerDomain": 20
};

const run = await client.actor('v0iddo/sitemap-url-extractor').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~sitemap-url-extractor/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"domains": ["stripe.com", "shopify.com", "vercel.com"], "maxUrlsPerDomain": 20}'

FAQ

What data does the Sitemap URL extractor return?

Each result is one row in an Apify dataset. Fields include domain, url, lastmod, changefreq, priority, source. The table above shows every field with an example value.

How do I use the Sitemap URL extractor from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/sitemap-url-extractor with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.
