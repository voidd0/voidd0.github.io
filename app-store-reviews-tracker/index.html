Input fieldTypeWhat it does
appIdsarrayNumeric Apple App Store IDs or App Store URLs.
countriesarrayApp Store storefronts as ISO 3166-1 alpha-2 codes, for example us, gb, de, fr, jp, br, in.
sortBystringmostRecent (default) lists each storefront's reviews newest first; mostHelpful keeps the order Apple shows them in.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/app-store-reviews-tracker.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'appIds': ['389801252', '544007664']}

run = client.actor("v0iddo/app-store-reviews-tracker").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "appIds": [
    "389801252",
    "544007664"
  ]
};

const run = await client.actor('v0iddo/app-store-reviews-tracker').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~app-store-reviews-tracker/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"appIds": ["389801252", "544007664"]}'

FAQ

What data does the App Store Reviews Scraper return?

Each result is one row in an Apify dataset. Fields include appName, country, rating, title, body, date, storefrontRating, storefrontRatingCount, and more. The table above shows every field with an example value.

How do I use the App Store Reviews Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/app-store-reviews-tracker with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.16 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.11 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
