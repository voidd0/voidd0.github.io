Audio transcription: how to turn audio and video into text (API, Python, no code)

Speech to text with Whisper: transcribe audio and video files and podcast episodes, with timestamps and SRT or VTT subtitles. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/audio-transcription on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "mediaUrls": [
    "https://upload.wikimedia.org/wikipedia/commons/5/50/Jfk_rice_university_we_choose_to_go_to_the_moon.ogg"
  ],
  "maxMinutesPerFile": 8,
  "maxItems": 1
}
Input fieldTypeWhat it does
mediaUrlsarrayDirect links to media files: MP3, M4A, AAC, WAV, OGG, OPUS, FLAC, MP4, MOV, WEBM and more.
podcastFeedsarrayRSS feed links of podcasts.
episodesPerFeedintegerHow many of each feed's newest episodes to transcribe.
episodeKeywordsarrayKeep only feed episodes whose title holds one of these words.
languagestringThe language spoken in the files.
taskstringWrite the text in the spoken language, or translate it to English.
modelstringSpeech recognition model.
maxMinutesPerFileintegerOnly the first this many minutes of each file are transcribed and charged; the row says when a file was cut.
includeSegmentsbooleanReturn the transcript also as segments with start and end seconds.
includeSubtitlesbooleanReturn the transcript also as SRT and WebVTT subtitle text.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/audio-transcription.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'mediaUrls': ['https://upload.wikimedia.org/wikipedia/commons/5/50/Jfk_rice_university_we_choose_to_go_to_the_moon.ogg'],
 'maxMinutesPerFile': 8,
 'maxItems': 1}

run = client.actor("v0iddo/audio-transcription").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "mediaUrls": [
    "https://upload.wikimedia.org/wikipedia/commons/5/50/Jfk_rice_university_we_choose_to_go_to_the_moon.ogg"
  ],
  "maxMinutesPerFile": 8,
  "maxItems": 1
};

const run = await client.actor('v0iddo/audio-transcription').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~audio-transcription/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mediaUrls": ["https://upload.wikimedia.org/wikipedia/commons/5/50/Jfk_rice_university_we_choose_to_go_to_the_moon.ogg"], "maxMinutesPerFile": 8, "maxItems": 1}'

FAQ

What data does the Audio transcription return?

Each result is one row in an Apify dataset. Fields include fileName, episodeTitle, language, durationSeconds, billedMinutes, wordCount, text, mediaUrl, and more. The table above shows every field with an example value.

How do I use the Audio transcription from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/audio-transcription with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$10.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $7.00 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
