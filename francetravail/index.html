France Travail Scraper: how to get Pole Emploi Jobs and Salaries as JSON/CSV (API, Python, no code)

Scrape France Travail (ex Pole Emploi) job offers by town or department, ROME domain and contract type: title, company, town, contract and its length, weekly hours, schedule, salary with its period and minimum and maximum in euros, benefits, posting age, source and offer link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/francetravail on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/francetravail.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'locationCodes': ['75D', '69D'],
 'domainCode': 'M18',
 'contractType': '',
 'includePartners': True,
 'includeSalary': True,
 'maxItems': 20}

run = client.actor("v0iddo/francetravail").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "locationCodes": [
    "75D",
    "69D"
  ],
  "domainCode": "M18",
  "contractType": "",
  "includePartners": true,
  "includeSalary": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/francetravail').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~francetravail/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"locationCodes": ["75D", "69D"], "domainCode": "M18", "contractType": "", "includePartners": true, "includeSalary": true, "maxItems": 20}'

Good to know

  • Covers candidat.francetravail.fr (France). Location codes are 5-digit INSEE commune codes (e.g. 75056 for Paris) or department codes with a D suffix (e.g. 75D, 69D).
  • Each page returns 20 listings; the scraper reads up to 50 pages per location (1,000 offers). Use the ROME domain code and contract type inputs to narrow results.
  • Working hours is null when the listing does not specify it (shown as Non renseignee on the site). Full descriptions are in a JS component and not included; the snippet field holds the card-level...
  • Salary, hours per week, schedule, contract length, benefits and town come from each offer page (one more page per offer). salaryMin and salaryMax are euros per salaryPeriod (hourly, monthly or...

FAQ

What data does the France Travail Scraper return?

Each result is one row in an Apify dataset. Fields include offerId, title, companyName, location, city, contractType, contractDuration, workingHours, and more. The table above shows every field with an example value.

How do I use the France Travail Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/francetravail with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.70 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
