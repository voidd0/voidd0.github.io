Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/indeed-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'query': 'data analyst',
 'location': 'Remote',
 'datePosted': 'any',
 'jobType': '',
 'maxPages': 1,
 'maxItems': 20}

run = client.actor("v0iddo/indeed-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "query": "data analyst",
  "location": "Remote",
  "datePosted": "any",
  "jobType": "",
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/indeed-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~indeed-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"query": "data analyst", "location": "Remote", "datePosted": "any", "jobType": "", "maxPages": 1, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers indeed.com (United States) job search pages. Each page holds about 15 results; set maxPages to control depth. Indeed's robots.txt opens the first 10 result pages of a search, so a search...
  • Individual job detail pages (/viewjob) are closed to automated access in Indeed's robots.txt and are never fetched; jobUrl is provided as a reference link only.
  • Salary, posting date, job types and the remote flag are filled when Indeed shows them on the search card. Sponsored marks paid listings; turn off Include sponsored jobs to keep only the others.
  • Not affiliated with Indeed.

FAQ

What data does the Indeed Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, location, remote, salary, salaryMin, salaryMax, salaryPeriod, and more. The table above shows every field with an example value.

How do I use the Indeed Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/indeed-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
