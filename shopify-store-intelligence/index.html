Shopify Scraper: how to get Products, Prices, Stock as JSON/CSV (API, Python, no code)

Scrape products from any Shopify store: prices, compare-at price and discount, stock per variant, SKU, barcode, options, images, tags and the store's currency. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/shopify-store-intelligence on Apify.

rowModestring"perproduct" (default) gives one row per product with its variants nested.
keywordsarrayKeep products whose title, product type, vendor or tags contain one of these words (any case).

onlyOnSalebooleanKeep products priced under their compare-at price (with "per_variant", the variants that are).

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/shopify-store-intelligence.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'stores': ['gymshark.com', 'allbirds.com', 'kith.com'], 'maxProductsPerStore': 20}

run = client.actor("v0iddo/shopify-store-intelligence").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "stores": [
    "gymshark.com",
    "allbirds.com",
    "kith.com"
  ],
  "maxProductsPerStore": 20
};

const run = await client.actor('v0iddo/shopify-store-intelligence').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~shopify-store-intelligence/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"stores": ["gymshark.com", "allbirds.com", "kith.com"], "maxProductsPerStore": 20}'

FAQ

What data does the Shopify Scraper return?

Each result is one row in an Apify dataset. Fields include storeDomain, title, url, vendor, productType, minPrice, maxPrice, currency, and more. The table above shows every field with an example value.

How do I use the Shopify Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/shopify-store-intelligence with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
