This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/creator-leads-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/creator-leads-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'handles': ['stratechery',
             'noahpinion',
             'astralcodexten',
             'mattstoller',
             'platformer',
             'byrnehobart',
             'worksinprogress',
             'slowboring',
             'persuasion',
             'thedispatch'],
 'maxItems': 20}

run = client.actor("v0iddo/creator-leads-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "handles": [
    "stratechery",
    "noahpinion",
    "astralcodexten",
    "mattstoller",
    "platformer",
    "byrnehobart",
    "worksinprogress",
    "slowboring",
    "persuasion",
    "thedispatch"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/creator-leads-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~creator-leads-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"handles": ["stratechery", "noahpinion", "astralcodexten", "mattstoller", "platformer", "byrnehobart", "worksinprogress", "slowboring", "persuasion", "thedispatch"], "maxItems": 20}'

Price

$2.55 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.78 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each handle resolves to the newsletters that creator actively writes for; one row is emitted per publication found on their public profile.
  • Subscriber counts are not exposed in the public profile page JSON; visit the newsletter URL directly for additional details.
  • Handles with no public publications or a private profile are silently skipped; the run raises an error only when every handle fails.
  • Not affiliated with Substack.

FAQ

What data does the Substack Newsletter Scraper return?

Each result is one row in an Apify dataset. Fields include publicationName, publicationUrl, subdomain, description, hasPaidTier, paymentsState, homepageType, communityEnabled, and more. The table above shows every field with an example value.

How do I use the Substack Newsletter Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/creator-leads-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.55 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $1.78 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
