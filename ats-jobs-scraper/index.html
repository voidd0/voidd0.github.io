Input fieldTypeWhat it does
companies (required)arrayOne company per line, at most 200.
titleKeywordsarrayOptional. Only postings whose title contains at least one of these words or phrases are returned.
locationContainsstringOptional text such as Berlin, Remote, Canada or US.
remoteOnlybooleanReturn only postings that are marked remote or say remote in their location.
postedWithinDaysintegerOptional. Skip postings that were published longer ago than this.
includeDescriptionbooleanAdd the job description as plain text.
maxJobsPerCompanyintegerOptional. Stop reading a company after this many matching postings and go on to the next one, so a large employer first in the list does not fill the whole run.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/ats-jobs-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'companies': ['https://job-boards.greenhouse.io/discord',
               'https://jobs.lever.co/spotify',
               'https://apply.workable.com/huggingface'],
 'includeDescription': True,
 'maxItems': 50,
 'maxJobsPerCompany': 20}

run = client.actor("v0iddo/ats-jobs-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "companies": [
    "https://job-boards.greenhouse.io/discord",
    "https://jobs.lever.co/spotify",
    "https://apply.workable.com/huggingface"
  ],
  "includeDescription": true,
  "maxItems": 50,
  "maxJobsPerCompany": 20
};

const run = await client.actor('v0iddo/ats-jobs-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~ats-jobs-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"companies": ["https://job-boards.greenhouse.io/discord", "https://jobs.lever.co/spotify", "https://apply.workable.com/huggingface"], "includeDescription": true, "maxItems": 50, "maxJobsPerCompany": 20}'

FAQ

What data does the Greenhouse, Lever, Workday and Ashby jobs scraper return?

Each result is one row in an Apify dataset. Fields include ats, company, title, department, location, remote, workplaceType, employmentType, and more. The table above shows every field with an example value.

How do I use the Greenhouse, Lever, Workday and Ashby jobs scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/ats-jobs-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.20 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.84 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
