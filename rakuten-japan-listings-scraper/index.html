This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/rakuten-japan-listings-scraper on Apify.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/rakuten-japan-listings-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'keywords': ['カメラ'], 'maxPages': 1, 'maxItems': 20}

run = client.actor("v0iddo/rakuten-japan-listings-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "keywords": [
    "カメラ"
  ],
  "maxPages": 1,
  "maxItems": 20
};

const run = await client.actor('v0iddo/rakuten-japan-listings-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~rakuten-japan-listings-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"keywords": ["カメラ"], "maxPages": 1, "maxItems": 20}'

Price

$1.28 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.90 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Covers search.rakuten.co.jp (Rakuten Ichiba, Japan). Results and prices are shown as a guest visitor without a Rakuten account.
  • Rakuten caps search pagination at about 150 pages (roughly 6,750 items) per query. Paste a pre-filtered URL from the site to narrow results before scraping.
  • Prices are in Japanese Yen (JPY). Whether the displayed price includes consumption tax depends on each shop's display setting.
  • Not affiliated with Rakuten, Inc.

FAQ

What data does the Rakuten Ichiba Listings Scraper return?

Each result is one row in an Apify dataset. Fields include title, price, shopName, reviewScore, reviewCount, points, freeShipping, isSoldOut, and more. The table above shows every field with an example value.

How do I use the Rakuten Ichiba Listings Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/rakuten-japan-listings-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$1.28 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.90 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
