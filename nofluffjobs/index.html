Scrape IT job offers from No Fluff Jobs (nofluffjobs.com) in Poland: title, company, category, seniority, must have skills, work mode, city, salary from and to with currency and period, B2B or employment contract, date and link. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/nofluffjobs on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "technologies": [
    "Python"
  ],
  "salaryOnly": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
technologiesarrayTechnologies such as Python, Java, React, SQL or Spring Boot, one per line, as the site's technology filter.
categoriesarrayOptional site categories such as backend, frontend, fullstack, devops, data, testing, mobile or security, one per line.
keywordsarrayOptional words such as data engineer or fintech, searched the way the site's search box does.
locationstringOptional city such as Warszawa, Krakow, Wroclaw, Gdansk or Poznan (Warsaw and Polish letters work too), or remote or hybrid.
experienceLevelsarrayOptional. Only offers at these levels; empty means all.
contractTypesarrayOptional. Only offers with one of these contracts (B2B, employment contract UoP, mandate contract UZ, contract for specific work UoD); empty means all.
minSalaryintegerOptional. Only offers the site's own salary filter finds at this monthly amount in PLN or more.
salaryOnlybooleanLeave out the offers whose salary range the employer shows only at an interview.
sortBystringThe order of the site's listing: its default, newest first or highest salary first.
offersPerSearchintegerOptional cap for each search, so one search does not use the whole run.
splitLargeSearchesbooleanThe site lists the first 100 offers of a search.
offerPagesbooleanOff: one request reads up to 100 offers with the columns the listing shows (the first must have skills).
searchUrlsarrayNo Fluff Jobs listing pages copied from your browser, for example https://nofluffjobs.com/pl/warszawa/backend .
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/nofluffjobs.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'technologies': ['Python'], 'salaryOnly': True, 'maxItems': 20}

run = client.actor("v0iddo/nofluffjobs").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "technologies": [
    "Python"
  ],
  "salaryOnly": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/nofluffjobs').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~nofluffjobs/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"technologies": ["Python"], "salaryOnly": true, "maxItems": 20}'

Good to know

  • One search runs per technology, keyword and category (categories crossed with the technologies and keywords), in the city you choose and with the filters you set. Pasted listing URLs keep their...
  • The site's listing shows the first 100 offers of a search. A search with more is read again for each seniority level (Read large searches per seniority, on by default), so one search gives up to...
  • salaryFrom, salaryTo, currency, salaryInterval (month, day, hour or year) and salaryType are the employer's own figures for contractType, the contract the offer card shows. B2B rates are net...
  • contractType and contractTypes are in English: B2B, employment contract (umowa o prace, UoP), mandate contract (umowa zlecenie, UZ), contract for specific work (umowa o dzielo, UoD) and internship.

FAQ

What data does the No Fluff Jobs Scraper return?

Each result is one row in an Apify dataset. Fields include title, companyName, category, seniority, workMode, city, skills, salaryFrom, and more. The table above shows every field with an example value.

How do I use the No Fluff Jobs Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/nofluffjobs with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.75 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.53 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
