PriceCharting Scraper: how to get Game, Card and Collectible Prices as JSON/CSV (API, Python, no code)

Scrape PriceCharting prices for video games, Pokemon and other trading cards, comics, coins, Funko Pops and LEGO: loose, complete and new prices of every product in a console or set, or of a search. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/pricecharting-product-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "startUrls": [
    "https://www.pricecharting.com/console/super-nintendo"
  ],
  "maxItems": 20

Input fieldTypeWhat it does
startUrlsarrayPages of pricecharting.com, one per line: a console or set page such as https://www.pricecharting.com/console/super-nintendo or https://www.pricecharting.com/console/p...
searchTermsarrayOptional words such as zelda ocarina, charizard base set or a UPC barcode, searched as the site's search box does.
searchCategorystringOnly products of this category in the searches.
sortBystringThe order of console, set and search pages: the site's own (popularity), alphabetical, highest price first or biggest price change first.
productPagesbooleanOff: one request reads 150 products of a console or set, with the three prices the list shows.
priceHistorybooleanAdd the monthly price history of the site's chart to every row, one point per month and price column since the site tracks the product.
productsPerSourceintegerOptional cap for each console, set or search, so one large console does not use the whole run.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/pricecharting-product-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'startUrls': ['https://www.pricecharting.com/console/super-nintendo'],
 'maxItems': 20}

run = client.actor("v0iddo/pricecharting-product-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "startUrls": [
    "https://www.pricecharting.com/console/super-nintendo"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/pricecharting-product-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~pricecharting-product-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"startUrls": ["https://www.pricecharting.com/console/super-nintendo"], "maxItems": 20}'

Price

Good to know

  • A console or set page gives every product it lists, 150 per page in the order you choose; a search gives up to 100 products; a product page gives one row with every price. Each product comes once...
  • All prices are in USD as PriceCharting computes them from completed sales. prices holds every price of the row under the site's own column name (Loose, Complete, New, Ungraded, Grade 9, PSA 10...
  • loosePrice is the item alone: loose for games, ungraded for cards, comics and coins, out of box for Funko, pieces only for LEGO. cibPrice and newPrice are complete in box and new or sealed...
  • Read each product page is off by default. Turned on, every product's own page is read as well (one more request per product, so a run takes longer) and fills gradedPrice, boxOnlyPrice and...

FAQ

What data does the PriceCharting Scraper return?

Each result is one row in an Apify dataset. Fields include productId, title, consoleName, loosePrice, cibPrice, newPrice, imageUrl, url, and more. The table above shows every field with an example value.

How do I use the PriceCharting Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/pricecharting-product-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$4.25 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.98 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
