Moz Top 500 Scraper: how to get Domain Rankings as JSON/CSV (API, Python, no code)

Scrape Moz's Top 500 Websites list: rank, root domain, DA score, and linking root domain count. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/moz-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "minDaScore": 0,
  "maxRank": 500,
  "maxItems": 20
}
Input fieldTypeWhat it does
minDaScoreintegerOnly include entries with a DA score at or above this value.
maxRankintegerOnly return entries with a rank at or below this position (1 = most popular).
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/moz-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'minDaScore': 0, 'maxRank': 500, 'maxItems': 20}

run = client.actor("v0iddo/moz-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "minDaScore": 0,
  "maxRank": 500,
  "maxItems": 20
};

const run = await client.actor('v0iddo/moz-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~moz-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"minDaScore": 0, "maxRank": 500, "maxItems": 20}'

Good to know

  • The Moz Top 500 list contains exactly 500 entries updated periodically by Moz; a single page fetch returns all 500 rows so the actor makes only one HTTP request per run.
  • DA Score is a Moz proprietary 1-100 score based on linking root domains; scores are the integers shown on the public list page.
  • Individual domain detail pages (/domain-analysis/*) are closed to automated access per moz.com robots.txt and are never requested by this actor.
  • Not affiliated with Moz.

FAQ

What data does the Moz Top 500 Scraper return?

Each result is one row in an Apify dataset. Fields include rank, rootDomain, daScore, linkingRootDomains, externalUrl, url. The table above shows every field with an example value.

How do I use the Moz Top 500 Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/moz-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$7.65 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $5.36 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
