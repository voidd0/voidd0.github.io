Alibaba Supplier Shortlist by Price, MOQ and Trust: how to get the data as JSON/CSV (API, Python, no code)

Get a ranked shortlist of Alibaba.com suppliers for each product you name: each supplier scored on price against the market median, fit to your minimum order, Verified, Trade Assurance, years, rating and units sold, with its best offer and the reasons. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/alibaba-supplier-shortlist on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "searchTerms": [
    "led strip lights"
  ],
  "targetPrice": 5,
  "targetMOQ": 50,
  "maxPages": 2,
  "shortlistSize": 10,
  "maxItems": 20
}
Input fieldTypeWhat it does
searchTermsarrayProducts as a buyer would type them, one per line, for example led strip lights.
targetPricenumberThe most you want to pay per unit.
targetMOQintegerHow many units you plan to order first.
shortlistSizeintegerHow many suppliers each product's shortlist names.
maxPagesintegerAlibaba result pages (about 47 offers each) read for each product.
supplierCountriesarrayOnly suppliers from these countries: names or codes, for example China, Vietnam, IN, Hong Kong.
verifiedSupplierbooleanOnly suppliers with Alibaba's verified badge.
tradeAssurancebooleanOnly suppliers that take Trade Assurance orders.
minSupplierRatingstringOnly suppliers rated at least this (out of 5).
certificationsarrayOnly offers with any of these certifications, for example CE, RoHS, FCC.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/alibaba-supplier-shortlist.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'searchTerms': ['led strip lights'],
 'targetPrice': 5,
 'targetMOQ': 50,
 'maxPages': 2,
 'shortlistSize': 10,
 'maxItems': 20}

run = client.actor("v0iddo/alibaba-supplier-shortlist").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "searchTerms": [
    "led strip lights"
  ],
  "targetPrice": 5,
  "targetMOQ": 50,
  "maxPages": 2,
  "shortlistSize": 10,
  "maxItems": 20
};

const run = await client.actor('v0iddo/alibaba-supplier-shortlist').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~alibaba-supplier-shortlist/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"searchTerms": ["led strip lights"], "targetPrice": 5, "targetMOQ": 50, "maxPages": 2, "shortlistSize": 10, "maxItems": 20}'

Price

$490.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $343.00 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Reads Alibaba's public keyword pages (alibaba.com/wholesale/...), the same pages as our Alibaba Scraper; its search box pages are closed to automated access in robots.txt. Supplier contact details...
  • The score, out of 100: price 35 (how many offers read cost the same or more), order size 15, trust 35 (Verified 10, Trade Assurance 8, Gold Supplier 3, years up to 8, response rate up to 6), proof...
  • With a target price or order size, the suppliers that fit both come first, then the score decides. Each supplier's best offer is the one that fits best and then costs least; otherOffers lists up...
  • The market median is that of the offers read, so more pages give a steadier median and more suppliers.

FAQ

What data does the Alibaba Supplier Shortlist by Price, MOQ and Trust return?

Each result is one row in an Apify dataset. Fields include rank, score, supplierName, supplierCountry, bestPrice, bestMinOrder, fitsTargets, verifiedSupplier, and more. The table above shows every field with an example value.

How do I use the Alibaba Supplier Shortlist by Price, MOQ and Trust from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/alibaba-supplier-shortlist with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$490.00 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $343.00 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
