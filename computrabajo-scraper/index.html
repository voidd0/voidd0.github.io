This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/computrabajo-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "countries": [
    "mx"
  ],
  "keywords": [
    "contador"
  ],
  "location": "Monterrey",
  "includeDetails": true,
  "maxItems": 20
}
Input fieldTypeWhat it does
countriesarrayComputrabajo sites to search; each search term runs on each of them.
keywordsarrayJob titles or words such as contador, vendedor or desarrollador python.
locationstringOptional city, state or region such as Monterrey, Bogotá, Lima or Nuevo León.
postedWithinstringOnly postings published or updated in that period.
salaryOnlybooleanOnly postings that show a salary (not "A convenir").
remoteOnlybooleanOnly postings marked remote or hybrid (presencial y remoto).
searchUrlsarraySearch result pages copied from your browser, for example https://mx.computrabajo.com/trabajo-de-contador-en-monterrey .
includeDetailsbooleanRead each posting's page for the date first posted, contract type, schedule, industry, salary value, education, experience, languages, skills and the description.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/computrabajo-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'countries': ['mx'],
 'keywords': ['contador'],
 'location': 'Monterrey',
 'includeDetails': True,
 'maxItems': 20}

run = client.actor("v0iddo/computrabajo-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "countries": [
    "mx"
  ],
  "keywords": [
    "contador"
  ],
  "location": "Monterrey",
  "includeDetails": true,
  "maxItems": 20
};

const run = await client.actor('v0iddo/computrabajo-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~computrabajo-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"countries": ["mx"], "keywords": ["contador"], "location": "Monterrey", "includeDetails": true, "maxItems": 20}'

Price

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • One search runs per country and search term, with the city or region you chose. Pasted search URLs are read as they are. Postings are unique by ID across the whole run.
  • salaryText is the salary as the posting shows it. salaryMin, salaryMax (the same value: Computrabajo shows one figure), salaryCurrency and salaryInterval come from the posting page with details on...
  • postedDate is the date of the posting's last publication or update, from the search page's "Hace 3 horas" or "Ayer", the order Computrabajo lists results in. firstPostedDate, with details on, is...
  • contractType, schedule, industry, education, skills and the posting's own text stay in Spanish as published; workMode is onsite, hybrid or remote and employmentType is the posting's schema.org value.

FAQ

What data does the Computrabajo Scraper return?

Each result is one row in an Apify dataset. Fields include title, company, city, country, salaryText, contractType, schedule, workMode, and more. The table above shows every field with an example value.

How do I use the Computrabajo Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/computrabajo-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
