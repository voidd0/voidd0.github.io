Coles Price Scraper: how to get Specials, Unit Prices as JSON/CSV (API, Python, no code)

Scrape Coles Australia products by department, category or the specials pages: price, was price, unit price, half price and multibuy offers, stock, purchase limits and aisle. This guide shows the output fields, a working input, and Python, JavaScript and cURL code for the Actor v0iddo/coles-scraper on Apify.

Input example

This is the input that is pre-filled on the Actor page. Change the values for your own run.

{
  "categories": [
    "dairy-eggs-fridge/yoghurt"
  ],
  "maxItems": 20
}
Input fieldTypeWhat it does
categoriesarrayColes departments or categories as in the address of their page, for example dairy-eggs-fridge, dairy-eggs-fridge/yoghurt, or the full https://www.coles.com.au/browse/...
allDepartmentsbooleanRead all 17 food and household departments (about 30,000 products); raise Maximum results to match.
specialsstringAlso read the specials page: every special, or the half price ones only.
productUrlsarrayOptional Coles product pages (https://www.coles.com.au/product/...); each gives a row with details, which counts as 10 rows.
includeDetailsbooleanOpen each product's page for barcode, ingredients, allergens, country of origin and nutrition.
maxItemsintegerThe run stops after this many result rows.

Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/coles-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'categories': ['dairy-eggs-fridge/yoghurt'], 'maxItems': 20}

run = client.actor("v0iddo/coles-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "categories": [
    "dairy-eggs-fridge/yoghurt"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/coles-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~coles-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"categories": ["dairy-eggs-fridge/yoghurt"], "maxItems": 20}'

Good to know

  • Reads Coles' public department, category and specials pages. Its search box is closed to automated access in robots.txt, so the actor takes departments and categories, not keywords.
  • Prices, specials and stock are those Coles shows a visitor who has not chosen a store (its default online store); prices are in Australian dollars.
  • Sponsored tiles are left out, so a category gives the products Coles counts for it, each once.
  • Include details opens each product's page: barcode (GTIN), ingredients, allergens, dietary notes, country of origin and nutrition per 100 g where Coles shows them. A row with details counts as 10...

FAQ

What data does the Coles Price Scraper return?

Each result is one row in an Apify dataset. Fields include productId, name, brand, size, price, wasPrice, unitPrice, unitMeasure, and more. The table above shows every field with an example value.

How do I use the Coles Price Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/coles-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$0.50 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $0.35 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
