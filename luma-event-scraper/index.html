Code: Python, JavaScript and cURL

Get your API token in Apify Console under Settings, then Integrations. The Actor id is v0iddo/luma-event-scraper.

Python (apify-client)

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")

run_input = {'pageUrls': ['https://luma.com/nyc', 'https://luma.com/sf'], 'maxItems': 20}

run = client.actor("v0iddo/luma-event-scraper").call(run_input=run_input)
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item)

JavaScript (apify-client)

import { ApifyClient } from 'apify-client';

const client = new ApifyClient({ token: 'YOUR_APIFY_TOKEN' });

const input = {
  "pageUrls": [
    "https://luma.com/nyc",
    "https://luma.com/sf"
  ],
  "maxItems": 20
};

const run = await client.actor('v0iddo/luma-event-scraper').call(input);
const { items } = await client.dataset(run.defaultDatasetId).listItems();
console.log(items);

cURL

curl -X POST "https://api.apify.com/v2/acts/v0iddo~luma-event-scraper/run-sync-get-dataset-items" \
  -H "Authorization: Bearer YOUR_APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"pageUrls": ["https://luma.com/nyc", "https://luma.com/sf"], "maxItems": 20}'

Price

$2.98 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.09 per 1,000. See the pricing tab for your plan. A new Apify account gets $5 of platform credit every month.

Good to know

  • Each luma.com city or calendar page returns up to 20 upcoming events. Add multiple page URLs to collect more results.
  • Ticket price is the first public offer price shown on the listing. Exact venue address may be hidden for some events until RSVP.
  • Events with location type 'online' typically have no GPS coordinates.
  • Not affiliated with Luma.

FAQ

What data does the Luma Event Scraper return?

Each result is one row in an Apify dataset. Fields include name, startDate, endDate, locationType, city, fullAddress, latitude, longitude, and more. The table above shows every field with an example value.

How do I use the Luma Event Scraper from Python?

Install the apify-client package, create a client with your Apify API token, call the Actor v0iddo/luma-event-scraper with an input like the one above, and read the rows from the run's dataset. The Python snippet above does exactly that.

Can I use it without writing code?

Yes. Open the Actor page on Apify, fill in the input form (an example is already filled in), press Start, and download the results as JSON, CSV, Excel or HTML. You can also schedule runs there.

How much does it cost?

$2.98 per 1,000 results. You pay per result row. There is no separate charge per run. Higher Apify plans pay less per result, down to $2.09 per 1,000. A new Apify account gets $5 of platform credit every month.

How do I limit the number of results?

Set the maxItems input field to the number of results you need; the run stops there, so it also caps the cost of one run. You can also set a maximum cost for a run in the run options on Apify, and the run stops when it is reached.

Can I send the results to Google Sheets, Make, Zapier or n8n?

Yes. Apify datasets connect to Google Sheets, Slack, Make, Zapier and n8n, and a webhook can call your own service when a run finishes. You can also export the dataset as JSON, CSV or Excel.
